# 物理机制与近似

## 1. 几何、质量与支撑

墙体是完整长方体内的三维 Voronoi 分区。分布由种子驱动的确定性伪随机函数产生，采用两组错开的分布层和附加采样点，共 136 个单元。逐平面裁剪生成凸多面体，保留每个面对应的相邻单元和外表面标记。

可见多面体精确拼合。碰撞多面体相对各自质心缩小至 0.9995 倍，为接触求解留出少量裕量；这是几何近似，不把这些缝隙渲染成裂纹。

每块以均匀密度积分，计算体积、质心和完整惯性张量，再对角化到主惯性轴，使碰撞体、显示模型和刚体惯量采用同一坐标变换。转动惯量不是用包围盒替代。测试核对全部单元的体积、总质心以及组合惯量与完整长方体的解析结果一致。

触及墙体底边的单元作为静态固定单元；默认种子下为 16 块，其余 120 块为动态刚体。底边固定意味着它们不能被拔出，也不会发生基础破坏。基座本身和地面都是静态碰撞体。未固定的单元从初始状态就承受重力，经连接把负载传到基座。

球体质量独立输入，球体惯量随半径与质量更新。墙体每个动态单元的质量为体积乘以 1750 kg/m³；固定单元仍保留材料质量供界面显示，但在动力学中是无限质量支撑。

## 2. 连接如何承载与断开

每对相邻单元设置一个六自由度 LockConstraint，连接位置取实际共享面的面积质心。三个平移约束和三个转动约束同时传递反力与力矩。存续连接禁止这对单元相互接触，断开后恢复普通碰撞。

设共享面面积为 A，两单元质心距离为 d，截面对相应轴的面积二次矩为 I_i，截面模量为 Z_i。名义刚度 E = 8×10⁸ Pa：

```text
平移刚度 k = E A / d
转动刚度 k_i = E I_i / d
名义抗拉力 F₀ = s A
名义弯矩 M₀ᵢ = s Z_i
```

s 为界面输入的连接强度。转动方程使用引擎 LockConstraint 的 z、x、y 轴顺序和对应初始截面量。此模型并不把 LockConstraint 等同于严格的共转有限元梁。

每个物理子步求解完毕后，从各约束方程的 `multiplier` 取得力或力矩。令 n 为由 A 指向 B 的共享面法线，F 为作用于 B 的平移反力，M_i 为三个转动方程反力矩：

```text
N = F · n                        正值为受压
C = max(N, 0)                    压力
T = max(−N, 0)                   拉力
S = sqrt(max(0, |F|² − N²))       剪力
B = sqrt(Σ (M_i / M₀ᵢ)²)         组合弯曲比值

r_s = S / (1.5 F₀ + 0.55 C)
r_o = max(0, B + (T − C) / F₀)
r_c = C / (10 F₀)
r = sqrt(r_s² + r_o² + r_c²)
```

当 r ≥ 0.998 时，移除该连接。这个很小的阈值容差用于配合数值冲量上限。抗压限值取抗拉的 10 倍，压紧也提高剪切承载并抑制张开。系数是本演示的简化模型选择，没有材料试验依据，不代表通用混凝土准则。

为了避免“先按无限强度弹回、再宣布断裂”，连接在本次求解内已有冲量上限。平移方程正负上限依面法线分量区分压缩方向，转动方程采用对应弯矩限值，再乘以当前 dt。cannon-es 0.20 的求解器实际把方程 `maxForce/minForce` 用作 lambda 的限值，因此这里显式乘 dt。求解后输出的 multiplier 为 lambda/dt。

所有连接先按同一已求解状态判断，再统一移除。没有根据撞击点到碎块的距离删块，没有定时断裂，没有由按钮直接断裂，也没有添加爆炸速度。断裂时不创建或销毁碎块，不额外注入能量。

连接移除后，剩余连接仍接受重力、碎块接触与受力重新分配，从而可能继续失效。支撑搜索仅计算哪些单元仍通过连接到达固定底边；它用于显示“脱离支撑”和决定独立碎块是否允许休眠，**不负责引发断裂**。脱离支撑的几块材料也可能仍互相连着，并非每块都已成为独立碎片。

## 3. 接触、摩擦与上扬问题

球—凸多面体检测在所有面三角形中寻找最近点，不因顶点被先检查就优先选择更远的顶点。完整连接处的内部面、内部棱边不当作外露碰撞特征；墙外轮廓与断开后露出的边缘仍可接触。这个修改针对预切单元接缝产生的不合理斜法线。

碎块—碎块仍采用凸多面体窄相位碰撞。几何缓存仅缓存世界顶点、法线和去除平行重复的边方向，保持相同分离轴逻辑。回归测试用 36 组旋转、分离和接近的凸体对，与原引擎分离轴判定核对。

接触恢复系数为 0.025。接触摩擦采用两个切向方向，每个方向的冲量上限为 μ 乘以当步法向冲量；球体参与时 μ = 0.28，其他接触 μ = 0.62。两个独立切向限值是摩擦锥的方形近似，不是精确圆锥。采用 22 次迭代的顺序冲量求解。墙体有线性与转动阻尼；独立低速碎块可休眠，因此最终可停止。

球体沿 −Z 水平发射，初始 v_y = 0；根据估算飞行时间 t 设置初始高度 `目标高度 + ½gt²`。全部后续速度由重力、阻尼、接触和约束求解决定。没有强制的“上扬”或“向下压”后处理。

正确现象是：固定、平直、无重力的墙面受到正向水平撞击时，球不获得竖直速度；而翻转碎块、外边缘、地面或倾斜断面可以给球一个竖向冲量。测试中的前者最大竖直速度约 8.72×10⁻¹⁷ m/s。高能穿透与低位重击中仍观察到向上偏转，不能把它们都判作错误或人为抹除。

## 4. 步进、轨迹与性能

模拟使用 1/120 s 主时钟。每个主步至少分为两个子步，并根据可能接触物体的相对线速度、角速度乘包围半径、墙厚与球半径增加子步。候选对使用扫掠 AABB 估计，远处飞行碎块不会无条件拖慢整个场景。

```text
clearance = 0.32 × min(墙厚, 球半径, 0.22 m)
子步数 = max(2, ceil(候选接触速度 × 主步长 / clearance))
```

这是降低离散碰撞漏检风险的办法，不是精确的扫掠凸体连续碰撞求解。对子步数超过 80 或出现非有限状态的情况会暂停并显示数值保护信息，不截断速度、不删除失控碎块、不悄悄重启。

每帧给物理计算分配约 12 ms 预算。设备来不及计算时会减慢模拟时间推进，并显示负载提示；不会增加物理 dt 来追赶墙钟。渲染帧率和模拟时间推进速度并不是一回事。

橙色轨迹来自球体质心位置，青色轨迹来自最多六个实际脱离碎块。它们没有控制运动。虚线只在发射前表示估算弹道。正常记录的轨迹每两个主步采样，最多显示游标之前的 900 个点；长记录降采样后使用保留帧。在回放时不会显示该时间点之后的运动或尚未产生的碎块轨迹。实时数值历史保留最近 7200 个主时钟样本；回放数值历史来自保留的帧。

### 回放与求解器隔离

`ReplayTimeline` 在每个完整主步之后保存所有墙块和重物的姿态、线速度、角速度、受力比值与统计数据。几何无需重复保存。连接断开时刻沿用真实模拟事件，回看时按游标时间重建连接状态和到基座的支撑路径。回放状态只供渲染、拾取信息和读数使用，不包含一个重新推进的物理世界。

拖动时暂停播放。回放播放采用同一 120 Hz 主时钟和慢放倍率；到达已记录终点自动暂停。回到最新状态后使用原求解器继续模拟，不重建接触缓存、不恢复旧动力学状态、不产生从过去时刻分叉的新实验。

姿态快照使用 Float32，初始保留每一主步。姿态数组预算为约 64 MiB（对象、统计和 GPU 资源占用另计）；达到预算后把历史帧间距翻倍，继续保留首尾，下一次达到预算再翻倍。位置与速度在保留帧之间作线性插值，四元数作最短弧球面插值并归一化；受力和累计冲量使用不晚于游标的保留帧，断裂时刻不插值。长记录因此保留完整时间范围，但不是任意长度都保持原始逐步精度。回放的插值仅用于显示，绝不回写物理状态。

界面“累计接触冲量”为球与墙体单元接触的非负法向冲量标量之和，单位 N·s。它不是总动量矢量差，不包含地面接触和碎块间接触。小图每个样本是一个 1/120 s 主步内的这类冲量总和，不能直接当成力读数。断裂连接数是累计已断连接；“脱离支撑”是失去到固定底边的连接路径。

## 5. 模型不能回答什么

- 裂纹只能沿这 136 个单元之间已有的界面形成；不能生成任意新裂纹，单个自由碎块不会继续粉碎。平直断面仍会体现这种离散分区。
- 没有连续体声波、真实应变场、压碎细粉、钢筋拉结、塑性流动、疲劳或裂纹尖端模型。
- 没有按断裂能校准的牵引—分离关系。仅仅移除连接没有完整的物理断裂耗能模型；不能由这里的动能换算实际材料破坏量。
- 采用刚体点接触。同质量、同速度的不同半径球体，正撞同一完整平面时，首次冲量和断裂数可能几乎一样。这是模型限制；半径仍改变真实几何接触、是否擦到墙边、惯量和与碎块/地面的相互作用。未模拟 Hertz 接触面积或材料局部压陷，不能保证裂口直径随半径真实缩放。
- 初始单元分区、约束轴、固定底边方式与求解容差都会影响结果。强度参数有量纲但未经标定。
- 小步长降低穿透与异常弹飞的风险，不保证所有输入组合都无穿透、无抖动。已验证的高速案例不能代表全部参数空间。
- 相同参数、种子和步数在本次 Node 环境下完全重复；跨浏览器、跨硬件的逐位一致未验证。
- 已测试的能量检查是“总机械能没有超出初始值 5%”的回归保护，且重力势能计入总和；它不是局部能量守恒证明，也不能证明材料破坏过程真实。

本项目的价值是让碰撞、承载不足、连接失效、碎块碰撞与重力运动之间的因果关系可见、可调整、可对照。现实结构的设计与安全评估需要经过验证和标定的专门工具。
