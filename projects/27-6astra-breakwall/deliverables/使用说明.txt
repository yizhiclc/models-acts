破壁 · 碰撞与断裂实验室

启动
直接使用现代浏览器打开 breakwall.html。脚本、样式和运行依赖全部内嵌，不使用 CDN。
自动测试环境不允许打开 file: 地址，所以“双击本地 HTML”未在此自动实测；同一内容已通过本地 HTTP 浏览器运行验证。

操作
1. 选择预设或修改参数，点击“应用参数并重置”。修改参数不会影响已经运行的实验。
2. 点击“开始撞击”；可暂停、继续、单步、重置，或选择 0.5/0.25/0.1 倍慢放。
3. 拖动旋转、滚轮缩放、右键平移；正面/侧面/透视按钮切换观察方向。
4. 点击球或碎块查看实际物理状态。连接受力和碎块边界可按需开启。
5. 在相同模拟时间记录实验，便于比较。种子固定时可重复相同实验。

新增：拖动时间轴回放
开始撞击后会自动记录整个已模拟过程。拖动场景下方的“过程回放”进度条会暂停，并恢复所选时刻的重物、碎块、断裂状态、读数与轨迹。
“从头回放”从 0 秒播放，到记录末尾自动暂停；回放时同样支持慢放和单步。
“回到最新”回到原来的物理状态，点击“继续模拟”可延长记录。回放不会重算或改变原来的撞击。
重置、应用新参数和刷新页面会清空本次回放。长记录达到约 64 MiB 姿态数据后会降低采样密度，并显示提示；起点、终点和断裂时刻保留，中间姿态插值。

质量与破坏
球的质量独立设置，改变半径不改变质量；可见球和球形碰撞体同步变化。
墙体密度为 1750 kg/m³，墙厚同时影响质量、碰撞体、连接截面和抗弯能力。
136 个三维不规则多面体通过可断裂连接传力。每一步根据实际连接反力、力矩与承载阈值决定断开；不按时间或固定撞击半径删除墙块。碎块拥有质量、转动和碰撞。
完整墙表面连续，不预画拼块接缝。球体使用最近表面接触，并处理未断裂的内部棱边，以减少错误斜向反弹。

实际验证
版本 1.1.0：13/13 组物理回归和新增 8/8 组回放测试通过，共 21/21 组。涵盖未命中、低冲击、撞击位置、参数变化、高速接触、重复运行、碎块落地，以及回放状态恢复、轨迹截取、回放后继续模拟和长记录起点保留。
水平撞击固定平墙、关闭重力的对照中，竖直速度误差约 8.72×10^-17 m/s。
默认局部损伤组运行至 2 秒时为 73 条连接断裂、1 块失去支撑；低冲击和未命中组均没有断裂。
完整结果见源码压缩包中的 TEST_REPORT.md 和 test/results.json。浏览器下载 JSON 的最终保存路径没有自动验证。

限制
这仍是预划分刚体模型，裂纹只能沿已有界面形成，自由碎块不会继续细化。没有真实材料标定、钢筋、塑性压碎或精确连续碰撞。不同半径的等质量球正撞完整平面时，初次冲量可能相近；没有模拟真实接触面积。
翻转碎块、斜边或地面碰撞可以产生向上偏转，程序不会强制篡改碰后速度。
它是观察物理因果关系的交互实验，不是工程级结构分析。

完整项目
解压 breakwall-project.zip 后，dist/index.html 是同一离线版本。
需要 HTTP 预览时，安装 Node.js，在解压目录运行 npm start，打开终端显示的本机地址（默认端口 4173）。
修改源码后：npm ci → npm run build。重新测试：npm test。
README.md 包含详细启动和操作说明；PHYSICS.md 解释方程、接触处理、步进和限制。
