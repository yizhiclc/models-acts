## 新增时间轴回放验证

回放测试包含：零时刻与实际模拟逐步记录；前后定位时恢复位置、旋转、速度、受力、连接与读数；碰撞前不泄漏未来裂纹、接触事件和轨迹；单步抵达末尾而不推进物理；回放后继续模拟与不中断运行完全一致；存储降采样仍保留首尾和离散断裂状态；超过原 60 秒统计窗口仍可回看起点；重建实验清空旧回放。

实际模拟恢复测试使用默认参数，并在多个时刻核对所有碎块及重物。Float32 姿态/速度误差容差为 2×10⁻⁶；连接状态、支撑状态、接触事件与累计冲量按原值核对。连续性对照同时核对位置、四元数、线速度和角速度。低帧预算测试故意使用 32 帧容量来触发降采样；超过 60 秒的存储测试使用合成线性运动 20,000 步，**不是长时间物理稳定性测试**。

浏览器中的实际操作：

- 高能穿透运行到 7.875 s，时间轴记录到第 945 步。回到 0 s 后，墙体恢复完整，接触冲量、断裂数、脱离数均回到零。
- 用鼠标实际拖动滑块到第 77 步（0.642 s），界面同步显示 394 条断裂、120 块脱离和约 23,971 N·s 接触冲量。
- 单步回放从 0.642 s 前进到 0.650 s；回到最新后单步模拟，将记录延长至 7.883 s / 第 946 步。
- 从头播放后在第 946 步自动停止，主按钮变为“继续模拟”，未额外推进或改变记录终点。此次浏览器日志未捕获 warning/error。
- 时间轴支持拖动、键盘定位、从头回放、返回最新；回放时仍可使用原有慢放选择。真实手机触摸手势未实测。

### 参数对照的实际结果

除明确指出的参数外，以下均使用默认组参数，运行至 1.5 s。同一个种子 42。

| 对照 | 较小/较弱一组：断裂连接；脱离单元 | 较大/较强一组：断裂连接；脱离单元 |

| 速度 5 / 24 m/s | 12；0 | 177；9 |
| 质量 70 / 700 kg | 10；0 | 224；3 |

## 浏览器人工操作验证

在本机内置浏览器，通过 `http://127.0.0.1:4187/` 打开与离线交付一致的内嵌 HTML：

- 看到完整连续墙面、基座、实体球；默认不开碎块边界。高能组运行至 0.733 s 时看到有厚度的散落/飞行多面体；不是用粒子代替实体。
- 开始、暂停、继续、重置、单步可操作。单步从零显示 0.008 s（1/120 s 的三位小数显示）。
- 修改预设后出现“参数已修改 · 应用后生效”；点击应用后重置为新参数。
- 0.25× 和 0.1× 慢放可选择并运行。未命中浏览器实验运行至 3.792 s，界面显示 0 接触冲量、0 断裂、0 脱离。

- 点击画布中的碎块可看到质量、速度、角速度、存续连接与支撑状态。
- 正面、侧面、透视视角切换和受力显示可操作。实验对比能记录当前参数、时间、接触与损伤结果。
- 机制说明弹窗可打开关闭；说明包含质量定义、断裂方法、数值限制和非工程分析声明。
- 当前窄窗口下场景在上、参数在下，没有画布按设备像素比溢出的现象。未完成真实手机设备测试。
- 最后读取浏览器捕获的 warning/error 日志为空。

## 尚未验证或仅部分验证

1. **直接双击离线文件**：内置浏览器安全策略拒绝 `file:` 协议，不允许自动打开该地址。已检查构建为内嵌脚本/样式，且通过同一内容的本地 HTTP 浏览器运行；不声称已完成断网或 `file:` 实机验证。
2. **数据下载落盘**：点击导出按钮后，浏览器自动化未返回下载完成事件，未确认最终文件保存路径。因此不能把“导出 JSON 已落盘”列为通过的浏览器测试。导出代码和内容结构在源码中可检查；Node 原始测试 JSON 已随项目直接提供。
3. **相机自由拖动/滚轮手势**：相关 OrbitControls 已实现，已验证视角按钮；未完成所有自由手势的自动回归。
4. **全参数组合及全部随机种子**：没有穷举。未命中涵盖种子 42 和 7，重复性验证使用种子 42。不能由这些测试推断所有极端组合都完全稳定。
5. **跨设备与长期运行**：未做 Safari、Firefox、手机、不同显卡的兼容性矩阵，也未做长时间压力测试。约束网络与大范围碎块碰撞的性能依赖 CPU。
6. **真实材料校准**：没有真实撞击试验对照、有限元对照或材料断裂能标定。所有 MPa 参数、剪切/压缩系数与刚度均为演示模型设置。
7. **测试精度边界**：碎块落地测试检查质心和速度，不等于逐顶点无穿透证明；高速案例证明该案例接触没有被跳过，不等于实现了严格连续碰撞；重复性测试核对连接状态和位置，没有建立跨引擎的逐位旋转一致性保证。
