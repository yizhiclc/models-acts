# 原始提示词

请设计并实现一个可在浏览器中实时运行、可交互观察的三维物理模拟：

《破壁》

【创作目标】

一个重物撞向墙面，使墙体产生局部破裂、碎块飞散与后续坍塌。重点表现碰撞、断裂和碎块运动之间可信的因果关系，而不是播放预制破碎动画。

【场景要求】

1. **真实碰撞驱动**

墙面破坏必须由实际碰撞产生的冲量、接触位置及墙体内部受力变化触发。破坏范围和程度应随冲击条件变化，不能根据时间、按钮或固定半径直接删除墙体。

未受到足够冲击时，墙体应保持完整；重物未撞到墙面时，不应发生破碎。撞击后的二次断裂或坍塌，应由碎块碰撞、连接失效与重力引起，不能无故全墙爆散。

2. **可调整的重物与墙体**

支持调整重物的大小、质量或密度、撞击速度及撞击位置。尺寸变化必须同步更新可见模型与碰撞体，并明确质量是独立设置，还是根据体积与密度计算。

墙体至少支持调整厚度和强度，使不同条件下能够观察到不破裂、局部破损、穿透或较大范围坍塌等不同结果，而非只改变同一种效果的播放幅度。

3. **破碎与物理运动**

允许采用预先划分的碎块、连接约束或运行时断裂方法，但**预先划分不等于预先决定破坏结果**：碎块何时脱离、哪些连接断开、碎块如何运动，必须由模拟状态决定。

碎块应具有碰撞体、质量和转动，能与重物、地面及其他碎块碰撞，并逐渐停止。墙体应有合理的厚度、支撑与固定方式，初始状态保持稳定。

粉尘和细小颗粒可作为辅助效果，但不能代替实体破碎，也不能掩盖明显的穿透或错误运动。

4. **交互与对比**

提供开始撞击、暂停、继续、单步、重置和慢放；支持旋转、缩放观察，并能查看碰撞前后细节。

参数修改后应明确何时生效。相同初始条件应尽量得到可复现的结果，便于比较不同尺寸、速度与墙体强度的影响。

【审美与体验】

采用清晰、简洁的非体素三维表现，突出墙体裂口、断面和碎块轨迹。界面不过度遮挡场景，控制项易于理解。

合理平衡碎块数量和实时性能。应采取适当的物理步进或连续碰撞处理，减少高速重物穿墙、碎块异常弹飞与模拟不稳定。

【交付】

交付完整、可运行的项目，并提供简短的启动方法、操作说明和破碎机制说明，明确物理近似与限制，不要将视觉演示宣称为工程级结构分析。

同时提供依赖全部内嵌、不依赖外部 CDN 的单文件 HTML 版本。

如进行了测试，请如实说明，重点验证：未命中不破碎、低冲击不无故爆裂、改变撞击位置会改变破坏位置，以及不同参数确实影响物理结果。未验证的部分不要声称已经验证。
