# 破壁 · Fracture Lab

浏览器中的三维碰撞与断裂实验。重物与墙体发生实际接触后，碰撞反力经墙体连接传递；连接承载不足时断开，碎块继续碰撞、转动和下落。用于交互观察与参数比较，**不是经过材料标定的工程级结构分析**。

## 直接运行

打开 `dist/index.html`，或打开单独交付的 `breakwall.html`。两者内容相同，JavaScript、CSS、Three.js、cannon-es、纹理生成代码和许可说明全部内嵌。运行不需要 npm、CDN、网络字体或服务器。建议使用支持 WebGL 2 的现代桌面浏览器并启用硬件加速。

本次自动浏览器验证使用同一 HTML 的本地 HTTP 预览。测试环境禁止访问 `file:` 协议，因此**未自动实测双击文件打开**；详情见 `TEST_REPORT.md`。

如果需要本地 HTTP 服务，安装 Node.js 后，在本目录运行：

```sh
npm start
```

打开终端显示的地址，默认 `http://127.0.0.1:4173/`。已有 `dist/index.html` 时，此命令只使用 Node 内置模块，不需要安装项目依赖。端口占用时，PowerShell 可运行：

```powershell
$env:PORT = '4187'
npm start
```

## 操作

1. 选择一个实验起点，或调整参数，然后点击 **应用参数并重置**。参数修改只进入草稿；不会改变当前世界。预设只是参数组合，不包含预制破坏动画。
2. **开始撞击**后，同一按钮变为**暂停 / 继续**。**单步**暂停播放并前进 `1/120 s`。慢放可选 `0.5× / 0.25× / 0.1×`。
3. **重置**使用已经应用的参数和同一种子。比较两组参数时，建议在相同模拟时间暂停后记录。
4. 拖动旋转，滚轮缩放，右键平移。可切换正面、侧面、透视，或恢复初始观察角度。
5. 点击重物查看三轴速度；点击碎块查看质量、线速度、角速度、剩余连接和支撑状态。连接受力颜色表示承载比值，不是连续体应力云图。
6. **实验对比**可保留最近 8 次记录；**导出数据**生成 JSON，含当前参数、首次接触、连接断裂事件、重物轨迹和对比记录。记录只保存在当前页面内存中，刷新会清空。历史曲线最多保留最近 7200 个主时钟样本。

### 拖动进度条回放

场景下方的 **过程回放** 时间轴会从零时刻自动记录本次模拟，无需另按录制。拖动进度条会暂停，并同时显示所选时刻的重物、碎块位置与转动、连接状态、受力颜色、数值和轨迹。

- **从头回放**：从 0 秒播放本次已经记录的全过程，到达记录末尾后自动暂停。
- 在过去时刻，主按钮显示 **播放回放**；暂停、慢放和单步继续可用。单步前进 1/120 秒。
- **回到最新**：返回原来的物理世界末尾。点击 **继续模拟** 会继续计算并延长本次记录。
- 滑块支持鼠标拖动、触摸以及键盘左右方向键、Home、End。淡绿色短线标记本次首次接触的时刻。
- 记录实验、检查碎块和导出当前结果时，使用的是正在查看的时间点。JSON 另外包含 `latest`（最新模拟结果）和 `viewingReplay`，避免把回放时刻与最新状态混淆。
- 重置、应用新参数或刷新页面会清空当前回放；实验对比列表仍只是结果快照，不保存其他实验的完整三维回放。

回放读取实际模拟生成的快照，不重新求解，也不把旧状态写回求解器。正常长度的记录每个 1/120 秒保存一次，位置和速度以 Float32 保存，旋转用归一化四元数。姿态数据达到约 64 MiB 后逐次降低采样密度，保留零时刻、最新时刻和全部断裂事件；中间位置/速度作线性插值，旋转作球面插值。长记录的运动细节和瞬时受力精度会降低，界面会提示。记录只在本页内存中，不能跨刷新恢复，也未实现三维回放文件导入。

快捷键：空格开始/暂停；`N` 单步；`R` 重置。输入框获得焦点时不会触发全局快捷键。切换到后台会暂停模拟。查看说明也会暂停。

## 参数含义

| 参数 | 范围 | 实际作用 |
| --- | --- | --- |
| 球半径 | 0.16–0.85 m | 同步改变可见球体、球形碰撞体和转动惯量 |
| 球质量 | 50–2400 kg | **独立设置**，改变半径不改变质量 |
| 入射速度 | 2–42 m/s | 沿墙法线、朝向墙体的初始速度 |
| 水平位置 | −5–5 m | 墙心为 0，可瞄准墙外 |
| 中心高度 | 0.5–5.2 m | 预计首次接触时的球心高度，以地面为零 |
| 墙厚 | 0.16–0.70 m | 重建三维单元、碰撞体、质量、共享截面和抗弯能力 |
| 连接强度 | 0.18–4 MPa | 简化连接的抗拉强度尺度；未经真实材料试验标定 |
| 碎块种子 | 1–99999 | 决定初始分区，同种子便于重复比较 |

墙面宽 6.4 m、高 3.8 m，底部位于 0.18 m 高的固定基座上；密度固定为 1750 kg/m³。墙厚 0.30 m 时材料总质量为 12,768 kg。底边单元固定，其他单元从开始就是参与求解的动态刚体。

重物初始竖直速度为零。发射高度补偿预计飞行期间的重力下落，不会给它一个向上的发射速度。空气阻尼和离散步进会带来小幅瞄准误差；球半径较大且瞄准高度很低时，也可能先接触地面。

## 关于预切痕迹与向上偏转

墙体使用 136 个在厚度方向错开、尺寸不一的三维 Voronoi 多面体。完整外表面保持连续纹理、颜色和几何拼合，不预画接缝；内部断面采用不同的粗糙度。默认关闭碎块边界显示。断开后会露出真实多面体断面。

球与多面体接触时选择最近的表面特征，未断裂接缝的内部棱边不作为外露棱边参与球体接触。这样避免球撞完整平墙时，被隐藏的预切棱边错误地向上顶起。接触摩擦上限也改为随当步法向冲量变化。

这仍然是预划分模型：潜在裂纹路径有限，碎块有平直多边形断面。**预划分决定可断的位置，求解状态决定是否断、何时断和之后如何运动。** 翻转碎块、真实斜边和地面接触仍然可以产生向上的速度；程序不会强制把碰后竖直速度清零或改成向下。

## 修改源码

本次构建和测试环境：Windows、Node.js 24.16.0。依赖版本已锁定。

```sh
npm ci
npm run build
npm test
npm start
```

`npm ci` 首次需要访问 npm 包源。`npm run build` 将源码及依赖打包到一个 `dist/index.html`，不生成运行时外部资源。`npm test` 顺序运行物理与回放回归测试，更新 `test/results.json` 和 `test/replay-results.json`。也可分别执行 `npm run test:physics`、`npm run test:replay`。

目录：

```text

src/contact.js              球体最近表面接触与内部接缝处理
```

## 使用边界

本项目采用小步离散碰撞和可断裂刚体连接，没有严格的连续碰撞时间求解，也没有有限元、钢筋、塑性、裂纹尖端、Hertz 弹性接触或真实压碎。连接强度单位有物理量纲，但不能用来预测某个实际混凝土构件的承载能力。低性能设备或大范围碰撞时，会降低模拟时间推进速度，保持物理步长与交互响应，不承诺所有设备稳定 60 FPS。

依赖官方资料：[Three.js 文档](https://threejs.org/docs/)、[cannon-es 源码](https://github.com/pmndrs/cannon-es)、[LockConstraint](https://pmndrs.github.io/cannon-es/docs/classes/LockConstraint.html)、[Equation](https://pmndrs.github.io/cannon-es/docs/classes/Equation.html)。具体实现与限制以本项目源码和 `PHYSICS.md` 为准。
