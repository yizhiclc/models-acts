## 在作品中的空间对应

世界坐标 X 向东、Z 向南，Y 为高度，单位为米。主城街区约 X=-76…22、Z=-75…79，西侧界石坪外伸至 X=-101；桩阵列位于 X=33…63；南岸位于 Z=60…85。

| 平面图要素 | 作品中的处理 |
|---|---|
| 界石坪 | 核心高塔中心位于 X=-88、Z=5，在主城西侧横轴尽端；按用户要求原地旋转 90°，正面朝东（+X），对着天师桩阵列；双立柱沿南北方向分布 |
| 息流行道、城内南北水道 | X=-29 附近的贯城水道、桥、灯柱与沿街工坊 |
| 方兴街、横向主轴 | Z=5 附近的东西街道、南北两排铺面与廊檐 |
| 选剑局与北部居民区 | 西北建筑院落与东北住宅街区 |
| 天师府学院 | 西南四面建筑围合的树庭 |
| 市民广场 | 东南阶梯方形水庭与环绕绿化 |
| 天师桩阵列、警戒区 | 主城东侧的重复高柱、开阔草地与东门中轴 |
| 陵水道与南部边界 | 南侧水岸、竹林、小亭和城台落水 |

核心塔使用公开城景中的造型语言，按用户指认放置在界石坪；相关指认图片保存在 `references/tower-location-note.png`。“水脉工坊”等为作品导览用语，不声称是原作正式地名。街区尺寸、层高、楼栋数量、地形为艺术化缩编；不是一比一实测复刻。远山为营造景深的背景地形，不是圈外可识别城区的重建。

模型、界面和声景均以程序生成。第三方游戏图片仅作参考，不用作场景贴图或替代三维模型。用户圈定图随项目保留用于核对范围。原作名称及世界观归原权利人所有。
