# 武陵城

基于《明日方舟：终末地》公开城景、平面图与用户圈定范围创作的实时三维体素主城。所有静态建筑和地形对齐 **0.2 m / voxel** 的整数网格。提供五处观景点、环绕游览、自由飞行、俯瞰平面图、昼夜切换、自动巡游与程序合成环境音。

## 启动

安装 Node.js 18 或更高版本，在此目录执行：

```sh
npm start
```

打开 **http://127.0.0.1:4173**。无需 `npm install`；Three.js 已附在 `vendor/`，运行时无外部 CDN、字体、模型或图片依赖。按 Ctrl+C 停止服务。不要直接双击 HTML，ES modules 需要 HTTP 服务。

也可以用 Python 3：`python -m http.server 4173 --bind 127.0.0.1`，再打开同一地址。

若端口占用，可在 PowerShell 执行 `$env:PORT=4174; npm start`，打开对应端口。需要支持 WebGL 2 的现代 Chrome、Edge、Firefox 或 Safari。建议开启浏览器硬件加速；较弱设备可选择“均衡”或“流畅”。

## 操作

| 操作 | 效果 |
|---|---|
| 鼠标左键拖动 / 右键拖动 / 滚轮 | 环绕 / 平移 / 缩放 |
| 底部观景卡片或 1—5 | 平滑切换五个观景点 |
| 入城漫游 | 从方兴街的行人高度开始探索 |
| F | 自由飞行 / 返回环绕 |
| 飞行时 WASD、Q/E、Shift | 移动、下降/上升、加速；拖动场景转向 |
| M 或小地图 | 俯瞰主城平面 / 返回观景 |
| 清昼 / 暮色 / 灯夜 | 更改天空、水色、照明与窗灯 |
| 自动巡游 | 每约 10 秒切换一处观景点；再次点击暂停 |
| H / R / Esc | 隐藏界面 / 回到全景 / 退出飞行或弹窗 |
| 右上角音量按钮 | 开关合成风水环境音，默认关闭 |
| 触屏 | 单指环绕、双指缩放和平移；飞行使用方向按钮 |

自由飞行允许穿越建筑，没有碰撞、重力或战斗系统。水面、船、水轮与漂浮粒子是实时动画；实体在运动时可以离开静态体素网格。

## 工程

- `src/world.js`：可编辑的主城布局、建筑、植被、桩阵列和地形。
- `src/grid.js`、`src/voxel.js`：0.2 米整数网格和连续体素长方体的批量表面网格生成。每个实体以整数格点边界保存，仅绘制其外表面；相接或重叠实体间未做全局布尔合并。
- `src/main.js`：渲染、镜头、交互、动画和照明。
- `src/style.css`、`index.html`：响应式游览界面。
- `vendor/`：Three.js 0.180.0 与 OrbitControls，许可证见 `vendor/LICENSE`。
- `REFERENCES.md`：实际检索来源、用户范围和布局对应。
- `TESTING.md`：此次交付的实际验证记录与边界。

项目是静态 ES module 应用。`server.mjs` 仅提供本机静态文件服务，不收集数据、没有云端后端。可将整个目录放到任意支持 JavaScript 模块的静态服务器上。

## 开发验证

```sh
npm test
```

测试格点尺度、三角形朝向、程序生成可重复性及主城范围。浏览器验证脚本为 `tests/browser-smoke.mjs`，使用可选 Playwright；详细执行方式见 `TESTING.md`。

这是主城的艺术化体素重构，非官方作品或原地图的逐点复刻。
