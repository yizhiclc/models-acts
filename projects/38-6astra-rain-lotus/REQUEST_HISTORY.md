## 请求 1

【任务】
请用 Three.js 和 WebGPU 创建一个可运行的"雨中荷塘"3D 场景:阴天细雨中的一方荷塘,水面有荷叶、荷花、莲蓬和挺出水面的茎秆。雨与水的相互作用,有接近光线追踪的真实光照:雨滴击水产生的涟漪会传播、叠加、被茎秆和荷叶边缘反射,荷叶上的水珠会滚动、汇聚、滴落,水面清晰映出天空和荷叶。

【场景要求】
1. 荷塘尺度取真实量级(单位为米,塘面约 6～10 米见方)。荷叶直径 0.3～0.6 米,带中央凹陷、叶脉和轻微起伏;荷花有多层花瓣,含花苞与盛开状态;莲蓬、茎秆与荷叶的连接关系正确,茎秆从水下伸出。所有模型由代码生成,细节可适度概括。
2. 水面为持久状态的波动模拟,运行在 GPU 上:
   - 每颗雨滴按落点和大小注入扰动,产生向外扩散的环形毛细重力波,在传播中衰减;
   - 多个涟漪相遇时自然叠加与干涉,而不是各自播放独立的圆环动画;
   - 茎秆、荷叶边缘和塘岸作为障碍物,波遇到后发生反射与绕射;
   - 荷叶覆盖的水面不受雨直接击打,雨只在开阔水面产生涟漪;
   - 波速与波长应符合毛细波量级(涟漪波长为厘米级,传播速度约每秒十几到几十厘米)。
3. 雨滴按真实量级生成:直径约 1～4 毫米,下落速度随大小变化,受风影响略有倾斜。落到水面时产生环形涟漪、小水冠和短暂气泡;大雨滴的响应明显强于小雨滴。
4. 荷叶与雨的相互作用:
   - 荷叶疏水,叶面上的水呈圆润水珠,而不是均匀水膜;
   - 雨滴落在叶面会聚成水珠,水珠沿叶面倾斜方向滚动,遇到其他水珠会合并变大;
   - 叶面中央凹陷处逐渐积水,超过容量后从叶缘溢出或滴落,滴落水珠进入水面并产生涟漪;
   - 荷叶受雨滴冲击有轻微弹性晃动,积水较多时下沉,并影响水珠的滚动方向。
5. 雨丝可见:近处是有拉伸和运动模糊的雨线,远处融入雾气;雨的密度、速度和倾角与水面上的击水数量一致。
6. 默认为阴天或黄昏的雨天,打开页面即可看到荷塘全景与正在下的雨。

【光照与视觉】
- 效果目标是接近光线追踪的真实感,具体实现自定(屏幕空间、探针、平面反射、软件光追均可),但须表现出:
  - 水面清晰、随涟漪扭曲的反射:反射荷叶、荷花、茎秆和天空;
  - 折射与透视:透过水面能看到水下茎秆、水草,并随视角发生位移;
  - 水滴作为微型透镜:荷叶上的水珠反射并倒置地折射周围环境,边缘有高光;
  - 接触阴影与环境遮蔽:荷叶下、茎秆基部有柔和的暗部;荷叶之间有互相遮挡的软阴影;
  - 花瓣的半透明:逆光时透出色彩,叶片薄处透光。
- 阴天光照为大面积柔和漫射光,天空有云层层次;要有体积雾或大气透视,远处荷叶逐渐融入雾中。
- 荷叶有湿润的暗色、叶脉和蜡质高光;花瓣为柔软的半透明质感;泥岸、石头、木栈道等材质可辨认。
- 使用 HDR 渲染、色调映射和景深,近景对焦时背景柔化。
- 静止视角下,推荐提供一个"高质量"模式:采用渐进式路径追踪或多帧累积,逐步收敛出更精细的反射、折射、软阴影和全局光照;移动相机时自动回到实时模式。

【交互要求】
1. 提供"雨量"滑杆,从零星小雨到暴雨连续变化。雨量变化时雨滴密度、大小分布、涟漪密度、水面粗糙度、荷叶晃动与滴落频率、雾的浓度随之变化。
2. 提供"风"控制,影响雨的倾角、水面细波与荷叶摆动。
3. 提供"暂停降雨"或"单滴模式":停雨后旧涟漪继续传播、反射、衰减,直至平静,便于观察波的行为。
4. 支持旋转、缩放、平移和复位;预设几个机位(全景、贴近水面、荷叶特写、俯视)。特写机位应能看清水珠和涟漪的细节。
5. 可选:时间流传，太阳月亮的角度变换带来变化。

【实现取向】
优先保证:水面涟漪的物理行为、雨与荷叶的相互作用、反射折射的真实感、荷塘整体构图与阴天氛围。荷叶、花的建模细节和植物数量自行取舍。

【技术要求】
- 使用 Three.js WebGPURenderer(TSL 或 Compute 均可),水面波动与雨滴击水的核心计算实际运行在 GPU 上;WebGPU 不可用时给出提示而不是白屏。
- 所有模型和材质均由代码生成,不加载现成的荷塘场景或 HDR 资源(程序化天空即可)。React 或原生均可,无需后端。
- 在工作区创建完整项目,可用 Vite,确保安装后可直接构建启动,并在 package.json 中锁定 three 版本。
- 页面打开后直接进入完整场景,长时间运行和视角操作保持稳定流畅。

【交付要求】
- 交付完整项目,README 写明安装、启动和操作方式,并简要说明:水面波动的方法与分辨率、障碍物与荷叶遮挡如何进入模拟、水珠与积水如何实现、GPU 承担的计算、反射折射与光追效果的实现方式、主要性能取舍和已知缺陷。
- 如果实际执行了构建、运行或功能验证,请如实说明结果;没有验证的部分不要声称已经通过。
