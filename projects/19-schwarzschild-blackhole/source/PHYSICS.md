# 物理模型与实现

## 1. 单位和时空

长度单位 `r_g = GM/c²`，时间单位 `t_g = GM/c³`。以下公式令 `G = c = M = 1`，角度为弧度。注意 `r_g` 不等于 Schwarzschild 半径，后者是 `r_s = 2 r_g`。

采用无电荷、无自旋、静态球对称的 Schwarzschild 度规：

```text
ds² = -(1 - 2/r) dt² + dr²/(1 - 2/r)
      + r² (dθ² + sin²θ dφ²)
```

光子满足 `ds² = 0`。利用球对称性，任意光线都位于包含原点的固定轨道平面中。定义 `u = 1/r`，总冲量参数 `b = L/E > 0`，在这个平面内用转角 `φ` 参数化：

```text
u'' = 3u² - u
(u')² + u² - 2u³ = 1/b²
```

该方程由零测地线和能量/角动量守恒约化而来，不是 Newton 引力近似。二阶形式可以连续处理近心点；渲染器实际上预存入射支，利用轨道对称性重建出射支。

事件视界 `r=2`，不稳定圆形光子轨道 `r=3`，临界冲量参数 `b_c=3√3`。从外部朝向黑洞追踪的光线在 `b <= b_c` 时被捕获，在 `b > b_c` 时有转向点；先遇到光学厚吸积盘的光线仍会显示盘面。

## 2. 预计算与重建

`scripts/precompute.mjs` 从无穷远的初值

```text
u(0) = 0
u'(0) = 1/b
```

以四阶 Runge-Kutta 积分，在 `4096 × 1024` 网格中保存入射支的 `(u, D)`，步长不大于 `π/(1023×3)`。使用双精度进行预计算，压缩保存 float32，运行时 GPU 手动双线性采样。

冲量参数采样采用

```text
s = asinh((b - b_c)/10^-5)
b ∈ [0.02, 220]
```

使临界曲线附近的样本密度远高于弱场区域。元数据保存转向角、转向延迟、转向点的 tortoise 坐标及半径倒数。转向点是三次方程

```text
2u³ - u² + 1/b² = 0
```

的最小正根。用 `u = u_turn(1 - s²)` 去除端点平方根奇点，适应性 Simpson 求积得到转向角和延迟。

薄盘内缘固定为 `r=6`。对于穿入 `r<6` 的入射支，只需保存到内缘，因为更深处不发射盘辐射；对于外部转向的轨道保存到转向点。出射支与入射支镜像配对。半支角度最多存储 `π`；在当前外缘和内缘范围内，发光盘的半支交点位于这一范围。

从观察者反向追踪，与盘面 `y=0` 的交点角由解析三角关系求得：

```text
n(φ) = cosφ e_r + sinφ e_t
e_r.y cosφ + e_t.y sinφ = 0
φ_k = φ_0 + kπ
```

按光行方向最多检查 8 个交盘点，选择第一个满足 `6 < r <= r_out` 的交点。不能直接把所有多重像相加，因为采用的是光学厚盘。低于像素分辨率的高阶环不会被保证解析。

恰好处于盘面内的共面光线是零厚度盘模型的退化情形，程序跳过这条共面盘求交；不伪造有限厚度。

## 3. 有限距离观察者

相机是半径 `r_o` 处的静止观察者，不是绕轨道飞行的观察者。OrbitControls 改变静止观察位置，旋转时不额外赋予相机速度或加入观察者多普勒效应。

令 `n` 为观察者正交标架中的单位光线，`n_t` 为其相对于径向的切向分量：

```text
b = r_o |n_t| / sqrt(1 - 2/r_o)
```

由 8 点 Gauss-Legendre 求积计算从无穷远到观察者的相位偏移：

```text
φ_o = ∫[0,1/r_o] b du / sqrt(1 - b²u²(1 - 2u))
```

再在无穷远初值表中使用 `φ + φ_o`。出射方向用 `2φ_turn - φ_o` 重建。当前相机始终朝向原点，距离限制为 `48..160 r_g`，并保持在盘外缘之外；不支持自由飞入视界。

窄屏会增大垂直视野，保持黑洞及盘在水平方向的可见范围。背景使用同样的弯曲光线查找天球方向；其亮度是艺术设定，没有实现相机高度变化对背景恒星光谱的引力蓝移。

## 4. 光行时延迟

Schwarzschild 坐标时间满足

```text
dt/dφ = 1 / [b u²(1 - 2u)]
r* = r + 2 ln(r/2 - 1)
D = t + r*
```

入射支可用守恒式稳定改写为

```text
dD/dφ = b / (1 + b u')
```

这样避免 `r→∞` 时两个发散量相减。出射支有

```text
D_out(r) = 2D_turn - D_in(r) + 2[r*(r) - r*_turn]
Δt = D_emit - D_obs + r*_obs - r*_emit
```

盘面亮度扰动在迟滞时间 `t_emit = t_obs - Δt` 取样。界面时间单位是 `t_g`，并非地球秒；时间速率 `24 t_g/s` 意味着每一现实秒推进 24 个引力时间单位。坐标时间显示是可视化时标，没有演化盘的质量或角动量。

## 5. Novikov-Thorne 盘与温度

选用赤道面圆形测地轨道、内缘零力矩、光学厚、几何零厚度的定常薄盘：

```text
Ω = r^(-3/2)
E = (1 - 2/r) / sqrt(1 - 3/r)
L = r / sqrt(r - 3)
r_in = r_ISCO = 6
```

令 `x=√r`，`x0=√6`，`a=√3`，无自旋 Novikov-Thorne 通量因子为

```text
Q(r) = [x - x0 - a/2 ln((x-a)(x0+a)/((x+a)(x0-a)))]
       / [x (r-3) r²]

F(r) = [3 c^6 Mdot / (8π G² M²)] Q(r)
T_eff(r) = [F(r)/σ_SB]^(1/4)
```

`r` 在 `Q` 中以 `GM/c²` 为单位，`M`、`Mdot` 在前置因子中采用 SI 单位。`r<=6` 发射为零。远场 `Q→r^-3`，不会用一条随意的径向亮度渐变替代这个剖面。

程序另允许对通量添加程序化非轴对称扰动，再以 `Ω(r)` 平流。该项只是被动发射率模型，既不是 MRI 湍流，也不是 GRMHD。设“平流亮度扰动”为 0 可得到严格轴对称的定常盘。

内缘以下无辐射，外缘硬截断。忽略盘厚度、边缘暗化、大气色温修正、返回辐射、热康普顿化、散射、吸收和盘自引力。整个滑块参数空间不都适用于定常薄盘近似，特别是低吸积率可能需要辐射低效热流、高吸积率可能需要厚盘。

## 6. 相对论频移和光谱

光子在真空传播时 `Iν/ν³` 不变。静止观察者接收到圆轨道盘面发出的光，频移为

```text
g = ν_obs/ν_emit
  = sqrt(1 - 3/r)
    / [sqrt(1 - 2/r_o) (1 - Ω λ)]
```

其中 `λ = L_y/E` 为**正向光子**沿盘轴的角动量/能量；程序向后追踪，因此 `λ = -b (e_r × e_t).y`。这个负号同时与盘的旋转纹理方向一致。

对局域黑体：

```text
Iν,obs(ν) = g³ Bν(ν/g, T_emit)
          = Bν(ν, g T_emit)
```

因此只把实际黑体温度变为 `gT`，再做光谱积分，已包含相对论增亮。不会再额外乘一次 `g³` 或 `g⁴` 而重复计算。全波段积分满足 `I_bol,obs = g⁴ I_bol,emit`，可见光则必须按观测频段积分。

预计算用 Planck 定律，在 360..830 nm、1 nm 间隔上乘 CIE 1931 2° 标准观察者函数，积分 XYZ，再转线性 sRGB。温度表为 200..2,000,000 K 的 2048 个对数采样。RGB 以 10,000 K 黑体的 Y 分量归一化，再应用曝光。显示不能替代完整光谱，超出 sRGB 色域的负分量会裁剪。

因此模拟不是固定“橙色黑洞”。质量、吸积率和频移决定盘的可见光颜色和亮度。不同曝光与色调映射也会显著改变最终外观。

## 7. 显示和性能近似

- 临界曲线用静止观察者关系 `sinα_c = b_c sqrt(1 - 2/r_o)/r_o` 放置，不是手绘环。
- 黑洞没有发光球体或专门叠加的“光子环”装饰；窄环来自光线与盘面的交点。
- 程序化恒星和暗弱星带不是实测天空。没有用照片替代黑洞。
- 辉光是可关闭的屏幕空间 PSF 近似，不进入光线方程。
- 曝光、ACES-fit 色调映射和 sRGB 编码属于显示转换。
- 自适应质量只调整渲染像素数量，不切换到 Newton 力学。
- float32 查表、角度插值、有限交盘阶次与有限显示像素不能解析数学上无限细的所有高阶环。
- WebGL 半浮点 HDR 缓冲和色调映射对极端高亮度有上限。
- 多帧累积仅在画面静止时进行，避免时间运动留下人为拖影。

## 8. 数值证据与局限

交付时的 8 项单元测试覆盖临界冲量参数、光子圆轨道、测地线一阶积分、弱场偏折、ISCO 转向点、薄盘温度缩放、频移符号、查表插值和有限观察者初值。

预计算所记录的最大双精度守恒残差约 `3.14×10^-11`。独立更小步长积分与查表在测试样本上的最大径向相对误差约 `1.06×10^-5`。

这两个数**不是全屏像素误差、不是临界曲线附近全局误差上界，也不是与 GRMHD/天文观测的验证**。它们仅描述当前数值单元测试中的量。实际运行检查记录在 `VALIDATION.md`。
