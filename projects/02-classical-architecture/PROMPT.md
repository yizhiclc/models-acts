# 原始提示词

【任务】
请创建一个可运行的3D体素（Voxel）风格中国古典建筑群场景，用Three.js实现，
浏览器打开即可观看，风格类似Minecraft体素块拼接。
【场景要求】
1.建筑群至少5座建筑，主次关系明确：
一主殿：体量最大，位于中轴线核心位置
一配殿：对称分布于主殿两侧
一山门：位于场地前端入口
-宝塔或钟鼓楼1-2座
2．空间布局：
一建筑间距合理（体素比例下足以容纳道路与庭院）
-有明确的道路动线连接：山门庭院主殿
-整体呈中轴对称的院落布局
3．建筑风格（中式古典）：
-屋顶：飞檐翘角，含歇山顶/房殿顶/攒尖顶等中式形制
结构：斗拱、立柱、台阶
—
·色彩：红墙、琉璃瓦或青瓦、木色构件
一细节：门窗、灯笼、石狮等酌情添加
4．环境与光影：
-地面有铺装/草地处理，建筑与地面自然衔接
-有明确光源与阴影，建筑群呈现光影层次与氛围
一可选：晨昏色调
【技术要求】
-使用Three.js（React或纯原生均可），无需后端
：
在工作区中创建完整项目（Vite等构建工具可用），确保可直接构建运行
画面流畅：体素数量合理，旋转视角时帧率稳定（≥30fps）
页面打开即进入场景，无需操作即可看到全部
