# 清和苑 · Three.js 体素建筑群

纯前端 3D 场景，采用 Three.js 和 Vite，无需后端。

## 直接打开

双击 `dist/index.html` 即可观看。Three.js、控件、样式和场景代码已经打包到同一 HTML 中，无需安装、无需联网，也无需服务器。

## 开发运行

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

在浏览器中打开终端显示的本地地址。

```sh
npm run build
npm run preview
```

构建结果是 `dist/index.html` 单文件，也可以部署到静态网站服务器。开发源码的根目录 `index.html` 需使用 Vite 启动；双击时应选择 `dist/index.html`。

## 场景

- 中轴后方：体量最大的重檐清和殿。
- 左右配殿：朝向庭院的听松殿、观澜殿。
- 前端入口：可通行的清和苑山门。
- 后方两角：三层钟楼、鼓楼。
- 院落：中轴石路、双水院、木桥、松树、花树、石狮、香炉、灯笼及围墙。
- 屋顶：体素庑殿式坡顶、重檐、攒尖式楼顶、上翘角部与金色屋脊。

鼠标拖动旋转，滚轮缩放，右键拖动平移。触屏支持单指旋转、双指缩放和平移。提供全景、中轴、主殿、俯瞰四个视角，以及日间、日暮和月夜三种照明。

## 实现

按材质和颜色合并 `InstancedMesh`，共享方块几何体，控制绘制调用数量。采用正交相机、方向光阴影、半球光和限制像素比的抗锯齿渲染。实际帧率取决于设备及其 WebGL / GPU 环境。

几何体、景观和匾额均在本地程序化生成，不依赖外部模型或图片，字体使用系统字体。
