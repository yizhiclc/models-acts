# 实际验证记录

日期：2026-09-28。验证范围为当前桌面内置浏览器，默认视口 1280 × 720。

## 安装、构建与加载

- 实际运行 `npm install`，依赖安装成功。
- 实际运行 `npm run build`，Vite 生产构建成功，无构建错误。
- 实际运行 `npm run dev -- --port 5173`，开发页面正常加载并直接呈现完整场景。
- 实际运行 `npm run preview -- --port 4173`，在浏览器打开生产构建产物，模型、字体、界面与本地资源正常呈现。
- 读取浏览器控制台，本轮验证中未发现 JavaScript 运行错误或着色器编译错误。

## 实际操作检查

- 鼠标拖动旋转：画面和相机位置随拖动变化。
- 滚轮缩放：缩放系数从 1.000 变为 1.369，随后复位恢复 1.000。
- 键盘方向键平移：相机观察目标确实变化。
- 复位按钮及 `R`：恢复全景及默认缩放；复位过程中清除之前拖动的惯性。
- 全景、临江、飞檐镜头：实际打开并检查。新增园林镜头在生产构建版本中打开，荷池、小桥、柳树和园路可观察。
- 时辰切换：实际查看 15:00、17:40 和 20:00，天空、水色、光照、窗灯与界面配色变化正常。滑块 End 键能准确到达 20:00。
- 环游：按钮启用自动环绕，手动拖动后自动停止。
- 暂停与继续：按钮状态与渲染状态一致，暂停时环境动画和环游停止。
- 静观模式：隐藏界面；`H` 可恢复，恢复后控件可继续操作。
- 建筑手记：能打开、关闭，并通过条目切换至对应建筑镜头。
- 江面与荷池反射：实际检查到舟、岸、树与建筑的镜像，夜色中也有灯火倒影。

右键平移及触屏手势使用 Three.js OrbitControls 的标准映射。平移通过键盘实际验证；未在本轮单独实测右键拖动和移动设备真机。

## 扩景与性能

- 河面底盘为 132 × 106 场景单位；相比最初 102 × 82 的方案，面积增加约 67%。
- 扩景包括柳岸步道、洲渚、码头、荷池、小桥、叠石、秋树与缓坡松林。
- 主阁与地景共 53,335 个实例化体素构件，另有少量舟鸟、云和水纹。
- 当前浏览器的前台全景样本约 60 fps；带反射的完整帧约 45 次绘制调用。后台标签页可能被浏览器限速，设备性能也会影响帧率。
- 帧循环设置约 60 fps 上限，页面隐藏时停绘；低帧率时会降低像素比。模型几何精度保持不变。

本记录不代表对所有浏览器、显卡与移动设备的兼容性保证。全屏权限差异、显卡上下文丢失后的恢复和长期压力测试未在本轮单独实测。
