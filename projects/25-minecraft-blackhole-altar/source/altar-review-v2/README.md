本版先交付完整建筑存档，直接进入游戏审阅，不另做截图交付。**未经确认，不启动施工过程拍摄，也不修改旧影片。**

在 PCL2 启动原有独立拍摄实例 `1.21.11-NeoForge_21.11.45-AltarFilm`，
在单人世界列表选择 **AltarReview-V2-20260925**。

建筑使用原版方块；黑洞沿用原实例已有的 Event Horizon 1.1.0。

## 本版改动

- 广场扩大到 161 × 161 格，最高 Y=172，形成完整的四层退台结构。
- 四根主柱与四道斜扶壁从地基连续落地，不再从半空起笔。
- 前后双冠环各自由两根主柱承托；按审阅反馈取消两圈之间的所有连接横杠。
- 四向楼梯使用相同的踏步与平台剖面，贯通墙体，保留净空与连续护栏。
- 原来悬空的中央护翼改为四根有完整基座的守卫柱。
- 新增四向入口拱门、立面拱龛、壁柱、主柱纹饰、嵌入式照明与广场四角灯塔。
- 图案和材质遵守左右、前后镜像；黑金配色保留，以石英细部区分结构层次。

## 审阅方法

直接进入世界查看，建议先关闭本机黑洞透镜显示，观察支撑、楼梯和中央平台；
再打开显示查看整体效果。两个圆环之间的连接横杠已经移除。

进入世界后可以使用：

```mcfunction
/blackholeview off
/blackholeview on
```

只切换本机透镜显示，不改变方块。黑洞位置为 `(0.5, 130, 0.5)`，质量尺度 1.5、自旋 0.94。
已知屏幕空间透镜近似仍存在，不能把透镜引起的扭曲当成建筑本体结构。

## 验证范围

`production/structural-audit.json` 检查方块连通、镜像材质与阶梯方向、
四根主柱落地连续性、楼梯净空及黑洞周围的实体净空。
这是体素几何检查，不是现实建筑的材料承载或力学认证。

运行时另核对实际放置的每个方块，结果见存档内 `altarreview-complete.json`。
本次修订 2 已实际生成 227,817 个方块，核对不匹配数为 0。
原世界文件的哈希检查与交付路径见 `production/delivery-report.json`。

## 重建

仅供修改成品审阅版，不包含新的施工摄影时间线：

```powershell
node .\generate-review.mjs
.\prepare-review.ps1
$env:JAVA_HOME='C:\Program Files\Java\jdk-21'
.\gradlew.bat build
.\gradlew.bat runClient
```

生成器只在独立 `run` 目录的指定审阅世界中工作，不访问用户已有世界。
运行后由 `publish-review.ps1` 在不覆盖现有目录的前提下复制到指定实例。
同一修订已有完成标记时不会自动重建。新修订仅可更新本项目独立运行时的指定世界；
发布到 PCL2 的世界不会被自动覆盖。再次设计应先保留用户已修改的存档。
