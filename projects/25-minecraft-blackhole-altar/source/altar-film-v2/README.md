## 源码

`catalog-approved.mjs` 对现有建筑标记施工部位，核对所有 227,817 个最终方块与批准蓝图一致。
`generate-film.mjs` 生成施工顺序与相机曲线，并检查相机轨迹不会进入建筑方块。
导演仅在带有专用标记、名称以 `AltarFilm-V2-` 开头的新拍摄世界中运行，拒绝重放已有施工进度的世界。

```powershell
node .\catalog-approved.mjs
node .\generate-film.mjs
$env:JAVA_HOME='C:\Program Files\Java\jdk-21'
.\gradlew.bat build runClient
```

运行后不会自行开始录制。OBS 的 `record.mjs setup`、`record.mjs record` 用于本地 WebSocket 控制，
录制前要求新世界已就绪且没有任何施工进度。再次拍摄应指定新的 `AltarFilm-V2-...` 世界名，
不能覆盖审阅存档或已录制的世界。
