# 黑洞祭坛剪辑

## 使用文件

- `BlackHoleAltar_Finished.prproj`：最终 PR 剪辑工程。
- `BlackHoleAltar_1080p60.mp4`：已由 PR 成功导出的成片，约 1.54 GB。
- `BlackHoleAltar_Linked.prproj`：已修复媒体链接的纯录像基础工程。
- `source_recording.mp4`：用于 PR 的兼容素材副本，重新封装但未重新编码。
- `assets/`：透明图文、音乐、文案与 SRT 字幕。

打开最终工程即可继续编辑。保持工程、`source_recording.mp4` 和 `assets` 的相对位置，
不要只移动一个 `.prproj` 文件。原始 OBS 录像仍在上一级的 `recording` 目录，未修改。

## 剪辑内容

- 1920 × 1080，60 FPS，时长 8 分 27.65 秒。
- 裁去正式施工前的等待段和施工结束后的静止尾段。
- 保留实际建造顺序与完整施工过程，没有瞬间跳过部件。
- 10 个施工阶段分别有中文标题；每阶段前约 10 秒显示部件介绍。
- 下方细进度条表示影片时间进度，不代表已放置方块的数量比例。
- 6 秒开场标题，首尾淡入淡出。
- 本地合成无歌词氛围配乐，72 BPM；音乐说明见 `assets/MUSIC-NOTES.md`。
