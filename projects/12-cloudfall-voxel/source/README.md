# 云岚 CLOUD FALL

Three.js 原生 JavaScript + Vite 实现的 3D 体素自然景观，无需后端。

## 直接观看

构建后，双击 `dist/index.html` 即可在支持 WebGL 的浏览器中离线观看。
所有 JavaScript、CSS、Three.js、图标均内联在这个 HTML 文件中，不依赖网络资源、外部模型或图片。

## 安装和启动

需要 Node.js 20.19+ 或 22.12+。

```sh
npm install
npm run dev
```

打开终端显示的本地地址。打开即进入全景，无需操作。

```sh
npm run build
npm run preview
```

开发时使用项目根目录的 `index.html`，直接双击时使用构建生成的 `dist/index.html`。

## 场景内容

- 五座高低不同的山峰，体素表面包含草坡、岩壁、山脊和浅色峰顶。
- 连续阶叠河床沿主峰南坡下行；水面、垂直落差水帘、水流粒子与落水飞沫共同构成瀑布。
- 瀑布汇入山脚湖泊，湖面有持续变化的细小波纹。
- 五组山腰云带缓慢漂移，采用三维透明体素及深度测试，形成山前、山后遮挡。
- 山脚松林、阔叶树、花草与观景台。
- 真实方向光阴影、半球环境光，以及清晨、日间、薄暮三种光照。

## 交互

鼠标左键拖动旋转，滚轮缩放，右键拖动平移；触屏支持单指旋转、双指缩放和平移。

底部提供全景、观瀑、云顶与俯瞰视角。工具栏可暂停水流与云雾、隐藏云雾、自动环游、保存 PNG 和恢复全景。

系统启用减少动态效果时，水流与云雾初始暂停，视角直接切换；可手动播放。

## 性能策略

共享方块几何体，按材质/颜色分组使用 InstancedMesh；仅细分可见岩壁层，避免大量内部隐藏方块。水流、飞沫和波纹使用动态实例化网格。像素比上限为 1.7，阴影贴图为 2048。

帧率受设备 GPU、屏幕分辨率及浏览器硬件加速设置影响，不保证所有设备均达到相同帧率。实际本机验证结果见 `VERIFICATION.md`。
