# Kerr 版本物理模型

## 1. 时空和坐标

本版本使用无电荷、定常、轴对称的 Kerr 黑洞，采用 Kerr–Schild 笛卡尔坐标。单位为 `G=c=M=1`，自旋参数为无量纲 `a* = Jc/(GM²)`，范围限制在 `|a*| <= 0.998`。

Kerr–Schild 形式写作：

```text
g_μν = η_μν + f l_μ l_ν
f = 2 r³ / (r⁴ + a² z²)
r² = 1/2 [ρ² − a² + sqrt((ρ²−a²)² + 4a²z²)]
ρ² = x² + y² + z²
```

外事件视界为：

```text
r+ = 1 + sqrt(1 − a²)
```

因此 `a*=0` 时回到 Schwarzschild 的 `r+=2`，自旋越高，外视界在 `r_g` 单位下越靠内。

## 2. 光线：Hamilton 测地线

对零测地线使用 Hamilton 方程：

```text
H = 1/2 g^μν p_μ p_ν = 0
dx^μ/dλ =  ∂H/∂p_μ
dp_μ/dλ = −∂H/∂x^μ
```

利用 Kerr–Schild 逆度规：

```text
g^ij = δ^ij − f l^i l^j
g^0i = f l^i
g^00 = −1 − f
```

固定反向追踪光线的时间动量尺度，浏览器端 GPU 每一步使用解析梯度的四阶 Runge–Kutta。光线从有限距离静止观察者的正交空间方向发射，然后转为 Kerr–Schild 空间动量。程序每步根据局部半径调整 affine 步长：

```text
Δλ ∝ r / |d x / dλ|
```

在靠近视界、径向变化快的位置进一步缩小步长。捕获条件为 `r <= r+ + ε`；到达 `r>1000` 的光线接回程序化天球。

盘面求交通过 `z=0` 的 Hermite 插值求根完成，而不是直接取一个粗糙步长的端点。每条光线继续积分，直到遇到第一个满足 `r_ISCO < r <= r_out` 的赤道盘交点。远侧盘、高阶交点和被捕获光线因此来自同一条三维 Kerr 测地线。

渲染器将每个像素的结果存入浮点纹理：

```text
x > 0       盘交点：x = r + 64 × imageOrder
x = -1      天球
x = -2      被视界捕获
x = -3      在预算内未收敛
```

视角稳定后，第二个 pass 对这张光线结果图着色并进行多帧累积。拖动时使用低积分预算，只缓存当前视角。

## 3. 盘轨道、ISCO 和频移

盘采用 Kerr 的赤道面圆形 prograde/retrograde 测地轨道：

```text
Ω = 1 / (r^(3/2) + a)
E = [r^(3/2) − 2 sqrt(r) + a]
    / [r^(3/4) sqrt(r^(3/2) − 3 sqrt(r) + 2a)]

L = [r² − 2a sqrt(r) + a²]
    / [r^(3/4) sqrt(r^(3/2) − 3 sqrt(r) + 2a)]
```

ISCO 使用解析根：

```text
Z1 = 1 + (1−a²)^(1/3) [(1+a)^(1/3) + (1−a)^(1/3)]
Z2 = sqrt(3a² + Z1²)
r_ISCO = 3 + Z2 − sign(a) sqrt[(3−Z1)(3+Z1+2Z2)]
```

所以在当前默认 `a*=+0.94` 时，`r_ISCO≈2.024 r_g`；切换到 `a*=-0.94` 时，`r_ISCO≈8.831 r_g`。这会真实改变盘的内缘和峰值温度，而不是只改变盘的动画方向。

观测频移使用发射圆轨道四速度和光子的角动量 `λ`：

```text
g = ν_obs / ν_emit
  = 1 / [u_obs^t u_emit^t (1 + Ω λ)]
```

其中 `u_obs^t = 1/sqrt(1−2/r_obs)`，`λ` 由反向追踪光线的轴向角动量符号得到。GPU 在盘交点保存 `g`，成像 pass 将黑体温度变为 `g T_eff`，从而使用 `Iν/ν³` 不变量。

## 4. Novikov–Thorne Kerr 盘

这里使用 Kerr 薄盘的一阶能量释放结构，内缘固定为 Kerr ISCO，外缘由滑块截断。用守恒量的 Page–Thorne 形式构建无量纲通量形状：

```text
F(r) ∝ −Ω'(r) / (E − ΩL)²
       × ∫[r_ISCO,r] (E − ΩL) L'(r) dr
```

实现中的 `circularOrbit` 给出 `Ω`、`E`、`L`、`L'` 和 `u^t`，对积分使用对数半径上的梯形加 Simpson 局部求积，生成 `2048` 个 `r_ISCO..48` 采样。零力矩边界使内缘通量从 0 开始，随后得到峰值：

```text
T_eff(r) = [F(r)/σ_SB]^(1/4)
```

吸积率、黑洞质量、CIE 1931 光谱和 Planck 黑体映射沿用 Schwarzschild 版本。时变亮度是按 `Ω(r)` 平流的程序化发射率扰动，不是 MRI 或 GRMHD 解。

## 5. 明确局限

- 没有磁流体、盘厚度、盘自引力、散射、吸收、返回辐射或视界附近辐射转移。
- 背景星场为程序化天球，不是实测星图。
- Hamilton RK4 使用有限步数，极近临界轨道可能进入“未收敛”标记。
- 页面中的曝光、辉光、ACES-fit 和 sRGB 变换属于显示处理。
- 质量和吸积率滑块是探索参数，并不保证每个组合都满足薄盘近似。
- 本版本的重点是 Kerr 光线几何与相对论成像，不是对具体天体的观测拟合。
