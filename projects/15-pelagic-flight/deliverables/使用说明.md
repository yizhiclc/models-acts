# 掠海长航

直接双击 **掠海长航.html** 即可打开。所有脚本、三维引擎、模型与材质生成程序、声音生成程序都在文件内，不需要联网或安装依赖。建议使用开启硬件加速的现代桌面浏览器。

本次海面修正取消了网格跳移，过滤远处无法被几何网格解析的短波，并减弱横向挤压与高频扰动，保留连续传播的长浪和近处掠过的细节。

| 操作 | 方法 |
|---|---|
| 旋转、缩放 | 拖动画面；滚轮 / 双指 |
| 暂停、继续 | 空格 |
| 重新开始 | R |
| 四种机位 | 1 跟随、2 伴飞、3 海面固定机位、4 全景 |
| 加速、减速 | + / −，或环境面板中的实际航速滑杆 |
| 发动机开关 | E，或底栏电源按钮 |
| 天气、昼夜 | 环境面板；小屏点击底栏调节图标展开 |
| 音量、静音 | M；底栏音量滑杆 |
| 隐藏界面、全屏 | H / F |

单圈航程现为 **25.25 公里**，默认 106 m/s 时约 **3 分 58 秒**。实际航速可设范围为 **80–360 m/s**，底栏的播放倍速独立控制演示时间。停机后推力消散、喷口冷却并逐渐减速，仍保持预设安全航线。飞行暂停会同步暂停海浪、植被风动与射流；昼夜时钟有自己的开关。

岛屿新增有树干和分枝的乔木、细叶树、棕榈，以及林下灌木、沿岸草丛。植物按坡度与海拔成片分布，叶片带细节、随风轻摆。可用伴飞机位和拖动观察近岸植被。

**掠海长航-完整项目.zip** 包含可编辑源码、引擎许可证、单文件 HTML、开发说明和测试记录。解压后可直接打开 `pelagic-flight/index.html`，也可在项目目录用 Node.js 执行 `npm start`，访问 `http://127.0.0.1:8080`。修改源码后执行 `npm run build` 更新单文件。

实际完成了离线浏览器运行、海浪时间与网格连续性检查、交互回归、18 分钟加速模拟推进和 2 分钟实际连续渲染；未做多小时或手机实机测试。详细结果见 `pelagic-flight/TESTING.md`。
