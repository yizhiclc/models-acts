# 实际测试记录

测试日期：2026-09-29。本次更新包含分层植被、25.25 公里航线、80–360 m/s 可设航速和高速滚转平滑。以下列明实际运行的检查；海面网格专项对照沿用海面修正版的记录，其位移算法本次未改动。

## 植被更新

十一处岛屿共生成 **15,279 株乔木、14,570 簇灌木、30,934 簇草丛**，以共享模型实例化绘制，不为每棵树创建独立渲染材质。树干、分枝、棕榈叶片与草叶使用三维几何，阔叶和细叶树冠采用带叶脉的镂空叶簇。

`tests/vegetation-browser.cjs` 对实际岛屿网格进行 **462 次向下射线检查**：根部埋入地形约 0.13–0.45 米，所测样本未悬空；全部植被根部最低约 4.515 米，高于保守海浪包络。

在独立植被场景中，仅改变风动时钟 0.25 秒，有 **6,446 个像素**变化；同一暂停时刻重复渲染的变化像素为 **0**。检查还覆盖了晴朗、多云、白天、夜间，以及最终滚转平滑后的 360 m/s 跟随和伴飞各一整圈，共 48 次目标可见性采样。

原始记录：`tests/vegetation-results.json`。植被特写、近岸跟随截图均由实际场景渲染，未使用绘画替代模型。

## 海浪连续性

此次修正取消了径向海面网格按 2 米步长跳移，增加近场采样密度，并根据网格间距过滤几何短波；降低横向挤压、短波振幅与高频扰动，使用 30 Hz 频谱状态及逐帧插值、mipmap 过滤与较慢的泡沫消散。

`node tests/ocean.cjs` 使用实际频谱实现，在 24 个固定世界位置以 120 Hz 采样 8 秒，同时沿 360 m/s 路径取样；另外检查 120 次 FFT 缓冲切换、暂停、跳帧和重播。

| 检查 | 结果 |
|---|---|
| 固定世界点每帧最大高度变化 | 0.02143 米，采样间隔 1/120 秒 |
| 固定点每帧高度变化 RMS | 0.00604 米 |
| 360 m/s 路径采样的最大相邻高度差 | 0.86899 米，包含每个样本沿海面前进 3 米的空间变化 |
| 缓冲切换前后 0.2 微秒内最大高度差 | 约 0.000000361 米，没有相位重置 |
| 暂停 | 两张纹理和插值因子保持不变 |
| 跳过较长时间后继续 | 高度匹配同一时刻的解析相位 |
| 重新开始 | 初始纹理逐字节一致，泡沫状态重新初始化 |

`node tests/ocean-render.cjs` 进一步使用**实际海面顶点着色器**，固定时刻，独立固定俯视相机读取 GPU 高度。观察网格每次移动 2 厘米，连续 121 帧，每帧读取 16,384 个世界位置。对照组只恢复旧的 2 米原点跳移，其他设置相同。

| 距网格中心 | 连续原点：最大相邻高度变化 | 恢复原点跳移的对照组 | 峰值降低倍数 |
|---|---:|---:|---:|
| 90 米 | 0.00585 米 | 0.04627 米 | 7.9 |
| 260 米 | 0.00053 米 | 0.03545 米 | 66.6 |
| 520 米 | 0.00094 米 | 0.07451 米 | 79.3 |

这项比较只衡量固定波场受到网格重定位的影响，不代表整个画面的主观真实程度提高了相同倍数。它与波浪自身的时间连续性检查分开进行。

原始记录：`tests/ocean-results.json`、`tests/ocean-render-results.json`。

## 航线、机体与碰撞

`node tests/verify.cjs` 对一整圈采样 12,001 次，检查机头朝向、运动方向、姿态相邻变化及机体边界代表点。航线长约 **25,251.62 米**，默认 106 m/s 时一圈约 **238.22 秒**。

- 以保守的 3.85 米总海浪高度包络检查，机体代表点最低余量约 **7.46 米**。
- 对岛屿高度场的最小机体间距约 **29.31 米**；保守岸线余量约 **77.13 米**，覆盖岸外散布岩石的尺度。
- 最大滚转约 25.21°，相邻数值样本姿态变化最大约 0.602°。
- 闭合航线首尾空间位置与朝向连续。

这些是航线与代表性机体边界的数值检查，不是对每个三角形做精确连续碰撞检测。飞行是预先设计的游览路径，停机后仍保持这条路径的安全高度。

额外使用 `tests/speed-range.cjs`，在 **80、106、360 m/s** 下各采样 16,001 次，全圈均通过机体朝向、海面余量、岛屿间距与闭合处连续性检查。三种航速的一圈时间约为 315.65、238.22、70.14 秒。最高速度下，相邻空间样本的姿态变化最大约 0.373°。

原始记录：`tests/route-results.json`、`tests/speed-range-results.json`。

## 浏览器交互与离线运行

实际测试环境：Windows、Chromium **153.0.8010.12**、NVIDIA **GeForce RTX 4070 Ti SUPER**，ANGLE / Direct3D 11。使用自动化浏览器直接通过 `file://` 加载单文件 HTML，并将浏览器网络上下文设为离线。

已通过：

- 离线首次加载及场景渲染；**0 次 HTTP/HTTPS 资源请求**。
- 飞行暂停、继续、重播、播放倍速；飞行与昼夜时钟独立暂停，昼夜跨过 24 小时边界。
- 手动昼夜不重置飞行位置；正午太阳和午夜月亮的位置随时刻变化；晴朗、多云双向渐变。
- 跟随、近景、全景各一整圈，共 108 次目标可见性检查；固定海面机位、掠过及返回跟随。
- 自由旋转、缩放、键盘操作，自动巡演及用户接管。
- 速度控件上下限为 80 和 360 m/s；从默认速度平滑加速到约 359.99985 m/s，再减速到约 80.00074 m/s，位置持续前进。
- 最高 360 m/s 下，跟随与伴飞各一整圈，共 72 次目标可见性检查通过；最终滚转平滑后另做 48 次检查通过。
- 发动机关闭后的推力消散、滑行减速和余热冷却，暂停时冻结冷却，重新启动后恢复推力和设定速度。
- 音频开关重复切换后只保留一个 AudioContext，没有重复创建音频图；**未进行主观听音评估**。
- 390 × 844 窄屏布局、目标可见性和无横向页面溢出；这是桌面窗口尺寸测试，**不是手机实机测试**。
- **0 个 JavaScript 或 GLSL 错误**。引擎旧式 UMD 分发格式会产生一条 Three.js 弃用提示，不影响本固定版本运行。

原始记录：`tests/browser-results.json`。

## 持续运行与性能

预热各航线区域后，快速推进 720 秒外部时钟，在 1.5 倍播放下相当于约 **18 分钟模拟航程**；随后实际连续渲染 **120 秒**。上述阶段的 GPU 资源计数保持为 **115 个 geometry、10 张 texture、22 个 shader program**，未观察到持续增长。此检查不等同于浏览器全部 CPU / GPU 内存的泄漏分析。

自动化快速推进会使自适应画质误判帧率，120 秒回归阶段内部像素比已降至 0.7，因此不把该阶段帧率当作原生 1600 × 1000 分辨率成绩。

另外执行了 **1600 × 1000、像素比 1、精细画质、多云场景的 30 秒实际渲染**，覆盖近岸植被航段。浏览器 requestAnimationFrame 平均间隔约 5.57 毫秒，95 分位约 5.60 毫秒。此数值是本机浏览器帧调度间隔，**不是 GPU 时间查询结果，也不保证其他机器的性能**。测试期间还运行了其他本地检查。

最终植被专项另以精细画质、像素比 1 运行 30 秒；该阶段主要位于外海，资源计数维持 113 / 10 / 22。因可见区域不同，首次按需上传的 geometry 数量也会不同，不把不同相机路径间的计数差当作持续泄漏。

原始记录：`tests/browser-results.json`、`tests/visual-results.json`、`tests/vegetation-results.json`。

## 射流与视觉核查

在同一暂停时刻、同一相机位置分别开启和关闭热折射，比较实际场景图像。1600 × 1000 画面中有 **23,369 个像素**变化，占约 1.46%，集中在投影后的尾部区域；说明热射流确实折射背景，影响范围局部。喷口温度、推力、射流强度与发动机状态同步。

检查了跟随、近景、后部、腹部、黄昏和夜间的实际截图，以及嵌入式浏览器中的更新画面。海水、岛屿、大气和射流均为程序化实时图形近似；射流不是 CFD，不能把“极度真实”当作已经通过客观验证的指标。

## 复现

基础测试无需安装依赖：

```sh
npm test
```

可选浏览器测试需要已有 Playwright 与 Chromium，通过 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_EXECUTABLE` 指定位置：

```sh
node tests/browser.cjs
node tests/ocean-render.cjs
node tests/vegetation-browser.cjs
```

`tests/browser.cjs` 默认实际渲染 120 秒，可以用 `QA_SECONDS` 调整。所有测试只生成本地 JSON 记录，不上传数据。
