# 掠海长航 · PELAGIC

一段可交互的海上飞行作品。虚构巡航飞行器「无定 M—07」沿约 **25.25 公里**的闭合航线，经过岛间水道、碎浪礁、望潮屿、长风屿与开阔外海。默认 106 m/s 时一圈约 **3 分 58 秒**。没有目标、攻击或命中场景。

## 直接打开

双击本目录的 **掠海长航.html**。这是完整的单文件版本，内嵌 Three.js、源码、样式，以及生成模型、纹理和音频的程序。运行期间不访问 CDN、字体服务、素材服务器或其他在线服务。

也可以直接双击 `index.html`，它读取本目录内的源码文件。请保留目录结构。

推荐现代桌面 Chrome / Edge / Firefox / Safari，开启硬件加速。实际验证的浏览器和硬件见 `TESTING.md`；其他浏览器与手机硬件未做实机验证。

## 本地开发

安装 Node.js 18 或更新版本即可，不需要安装项目依赖。

```sh
npm start
```

打开 <http://127.0.0.1:8080>。若端口被占用，可设置环境变量 `PORT`。服务器只监听本机。

```sh
npm run build   # 重新生成单文件 掠海长航.html
npm test        # 航线、姿态、岸线、海浪包络和频谱连续性检查
```

修改源码后必须重新运行构建，单文件版本才会更新。

## 操作

| 操作 | 方法 |
|---|---|
| 自由旋转 | 在画面空白处拖动；可观察正面、侧面、尾部和腹部 |
| 缩放 | 滚轮或触屏双指 |
| 暂停 / 继续 | 空格，或左下角播放按钮 |
| 重新开始 | `R`；恢复初始航线、速度、发动机、尾迹和机位，保留昼夜与天气设置 |
| 侧后跟随 / 近景伴飞 / 海面机位 / 全景 | `1` / `2` / `3` / `4` |
| 返回跟随 | `1`，或固定机位画面中的“返回跟随” |
| 调整实际航速 | 右侧“飞行动力”滑杆，或 `+` / `−`；范围 **80–360 m/s**，平滑加减速 |
| 发动机开 / 关 | `E`、底栏电源按钮，或右侧发动机按钮 |
| 播放倍速 | 底栏 `×` 按钮：0.5 / 1 / 1.5 / 2 倍 |
| 自动镜头巡演 | 点击“巡演”；拖动、缩放或选机位即可接管 |
| 天气 | 右侧晴朗 / 多云，云量、光照、海色和雾气逐渐过渡 |
| 24 小时时刻 | 拖动时刻滑杆；手动设置会暂停自动昼夜 |
| 自动昼夜 | 独立开关；24 分钟现实时间走完一日，不受飞行倍速影响 |
| 声音 | `M` 或音量按钮；默认静音，交互后开启，旁边可调音量 |
| 隐藏界面 / 全屏 / 说明 | `H` / `F` / `?` |

**航速与播放倍速不同。** 航速改变世界中的实际运动和转弯姿态；倍速只改变飞行演示时间推进的快慢。HUD 显示的是模拟世界中的航速，而不是倍速后的现实时间换算值。

**飞行与昼夜两套时钟独立。** 暂停飞行会冻结波浪、尾迹、推进和冷却过程；太阳和月亮仍可以继续移动。暂停昼夜不影响飞行。离开浏览器标签页后，场景停止累计时间，返回时不会突然跨过一大段航程。

**停机后有滑行过程。** 推力先平滑衰减，射流消散，机体继续前进并逐渐减速，喷口余热缓慢冷却。重新开启后恢复推力并向设定航速加速。为了保持游览可控，停机仍沿安全高度航线运行，不模拟坠落或完整无动力飞行包线。

## 画面实现

- 飞行器使用连续旋转曲面、带厚度的翼型、翼根整流、腹部进气道、喷口内壁和导流片；包含接缝、检修盖、紧固件及虚构涂装。模型可从各方向观察。
- 海面叠加长周期涌浪和 **128 × 128 Phillips 频谱 / 二维逆 FFT 风浪**。频谱按色散关系演化，两张固定纹理在帧间插值；不同尺度、不同方向的采样减少重复感。
- 海面网格连续跟随镜头，取消按 2 米步长跳移。近处加密，几何位移按照三角形间距过滤，避免粗网格硬撑短波；远处细浪由带 mipmap 的法线与反光表现。降低横向挤压与短波振幅，保留连续传播的涌浪，避免果冻式抽动。
- 破碎泡沫由波峰压缩产生并平缓衰减。岸线加入浅水色、冲刷带和局部泡沫。反射方向与日月光源一致。
- 十一处岛屿和礁石使用真实高度场，岸线不规则，具有山脊、陡岸、分布不均的沙滩、岩层细节与岸边巨石。
- 植被分为乔木、林下灌木与草丛：常绿阔叶树有三种冠形，另有沿岸细叶树和棕榈。树干与分枝为真实几何，叶簇带透明镂空、叶脉和色差；棕榈叶片、草叶分别建模。按坡度、海拔、林地斑块分布，树根贴合实际地形三角形。
- 植被共享实例化模型与本地绘制纹理，叶片轻微随风摆动，暂停时同步冻结；远处的灌木与草丛逐渐缩减。叶缘采用多重采样与覆盖抗锯齿。
- 云团使用真实三维包围盒中的密度场光线步进；另有薄云、雾气和程序化云影。云影、海面反射与大气散射是实时近似。
- 热射流包含短而低透明度的湍流气体、受推力影响的喷口亮度及余热。**热折射读取实际场景颜色与深度**，只扭曲射流后方的海水、岛屿或天空，避免拉扯前方机体轮廓。它不是计算流体力学模拟，也不使用火箭式大火柱。
- 默认航速 106 m/s。航线高度约 13–27 米，侧后镜头贴近机体并低于先前版本，利用近处波浪的实际掠过和远近视差表现高速。
- 航程由约 13.53 公里延长至约 25.25 公里，保留初段近岸掠过，增加外海长弧和两处岛屿。可设最低航速由 45 提高到 80 m/s，最高由 190 提高到 360 m/s。高速滚转使用沿闭合航线平滑后的姿态曲线，固定掠海机位随当前航速预留接近时间。
- 航线闭合，世界坐标维持在有限范围；海面使用随相机重新定位的径向网格，而海浪相位始终在世界坐标中计算。没有靠滚动海面贴图代替飞行。
- 海浪、云、尾迹、音频图与渲染目标有固定资源上限。短时翼尖凝结读取固定长度的真实飞行历史，能与加减速、停机、暂停和重播同步。

## 性能与测试

默认根据实际帧率降低内部渲染分辨率；右侧可选择精细或轻量画质。复杂效果的性能取决于显卡、屏幕分辨率和浏览器。不要把本机测试帧率当作其他设备的保证。

浏览器回归测试是可选开发工具，需要自行提供 Playwright 与 Chromium；运行作品不需要它们。可以设置 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_EXECUTABLE` 使用已有安装，再运行 `node tests/browser.cjs`。`QA_SECONDS` 控制实际连续渲染测试长度，默认 120 秒。输出保存在 `tests/browser-results.json`。

`node tests/ocean-render.cjs` 使用同一测试环境，冻结海浪时刻并连续移动采样网格，用固定俯视相机读取真实 GPU 位移，检查镜头移动是否引入高度突跳。这项检查与固定世界点的频谱时间连续性检查互相独立。

查看 `TESTING.md` 获取具体检查结果，包括哪些部分仅做了数值检查、哪些实际在浏览器运行，以及未覆盖的设备和长时间使用情形。
