# 深海启航 · The Silent Ascent

虚构潜艇 N–07 与「曙光」弹体的连续三维演示。全部模型、纹理、粒子和音频程序生成；Three.js 引擎已随项目提供。运行无需网络，也无需安装 npm 依赖。

## 立即打开

双击 `深海启航.html`，使用现代 Edge、Chrome 或 Firefox 打开。这个文件包含全部运行资源，可以单独复制到其他文件夹、U 盘或离线电脑。需要浏览器支持 WebGL 和硬件加速。

## 源码运行与构建

源码拆分在 `src/`，引擎和许可在 `vendor/`。

```text
node build.js              # 重新生成单文件 HTML 和源码入口 index.html
node serve.js              # 本地预览 http://127.0.0.1:4173
node tests/simulation.test.js
```

也可直接双击项目根目录的 `index.html` 运行源码版。默认服务器仅绑定本机 `127.0.0.1`，可用 `PORT` 环境变量更改端口。Node.js 仅用于构建、服务和命令行测试，观看单文件不需要 Node.js。

## 操作

| 控件 | 用法 |
| --- | --- |
| 开始 / 暂停 / 继续 | 点击左下按钮，或按空格 |
| 重置 | 点击 ↺，或按 R；恢复初始舱盖、弹体、粒子和推荐镜头 |
| 进度 | 可前后拖动；右侧阶段名称也可直接跳转 |
| 慢放 | 点击播放速度，在 1×、0.5×、0.25× 之间切换 |
| 五种视角 | 点击视角按钮，或按 1–5 |
| 自由观察 | 在三维区域拖动旋转，滚轮缩放；触屏支持双指缩放 |
| 自动运镜 | 开启后随阶段连续跟随；手动拖动或选择视角会退出 |
| 恢复构图 | 点击“复位视角”恢复当前推荐构图 |
| 昼夜 | 右上设置内拖动时间；可单独开始 / 暂停并调节流速 |
| 声音 | 默认静音；点击喇叭或按 M 开启，设置内调节音量 |
| 观察增强 | 默认开启；提高水下轮廓可读性，可在设置内关闭 |

发射演示为 28 秒，慢放作用于艇体、舱盖、弹体、气泡、水花、烟迹和波浪的统一任务时钟。昼夜时钟独立，重置发射不会重置昼夜、音量和播放速度偏好。

## 视觉与发射假设

- 所有型号、尺度和时间均为艺术示意，不对应真实武器性能、工程尺寸、内部步骤或控制系统。
- 采用一致的“水下冷发射，弹体完全出水后建立尾焰”表现。不同实际型号可能有不同的点火与出水细节。
- 短促出筒后，水下阶段按连续曲线惯性上行并总体减速；尾部离水后立即开始连续倾转，接着点火并沿弧线加速爬升。姿态、位移和喷焰方向一致，潜艇始终平稳移动。
- 正常场景有真实的开孔、筒内壁、底部、舱口环及铰链。未提供剖视模式。
- 海面是同一个网格界面；多尺度涌浪、细浪法线、场景反射、深度透射和飞溅均在同一空间中计算。
- 出水带起短暂水幕、飞溅及回落水滴。点火后的尾焰长度在近水面阶段受到可见水面的限制，水下没有持续火柱。
- 点火有迅速膨胀的灰白烟团、局部暖色闪光、海面反光和短促衰减的镜头震动，随后转为粗壮的白热喷流和浓密的弯曲烟柱。喷流使用柔和光晕与扰动边缘，烟柱从喷流末端接续、扩散。烟团留在发生位置逐渐扩散，不会粘着弹体一起飞走。
- 点击喇叭开启声音，可听到合成的点火低频冲击与发动机轰鸣。系统开启“减少动态效果”时，不施加点火镜头震动。
- 气泡、气团、喷溅、烟迹都从固定种子的出生事件按任务时刻求值，回退不会累积旧对象。

按用户意见参看了 [B 站发射演示视频](https://www.bilibili.com/video/BV1G84y1t7ia/) 约 1:18–1:31 的外部视觉过程，并加强了出筒气泡团、穿水水幕、出水点火和空中加速。视频中的动画仅作为观感参考；未复制其视频、音频或模型，也不把它作为真实工程依据。概念参考：[潜射弹道导弹概述](https://en.wikipedia.org/wiki/Submarine-launched_ballistic_missile)。这些链接只供阅读，运行不依赖它们。

## 文件结构

```text
深海启航.html              完全内嵌的交付版本
index.html                 读取本地源码的入口
src/index.html             页面模板与说明
src/style.css              界面与响应式布局
src/simulation.js          确定性任务时间轴、姿态与共用海面函数
src/water.js               波浪、反射、透射与海面材质
src/app.js                 模型、灯光、粒子、镜头、声音和交互
src/qa.js                  #qa 参数下启用的浏览器验收面板
vendor/three.min.js        Three.js 0.160.1
vendor/LICENSE-three.txt   Three.js MIT 许可
tests/simulation.test.js   时序、几何边界、连续性和离线打包测试
build.js / serve.js        零依赖构建与本机服务
TESTING.md                 实际测试范围、结果与未验证项
```

开发验收：在源码入口或单文件地址末尾添加 `#qa`，点击“运行一致性验收”。普通打开时不会出现该面板。

## 表现边界

这是风格化写实的实时可视化，采用程序化动画和简化水体模型，并非流体力学或飞行性能仿真。未使用体积流体求解、完整大气散射或路径追踪。镜面反射和透明粒子在极低掠射角可能有近似误差。性能取决于设备和浏览器，可在设置中降低渲染精度。
