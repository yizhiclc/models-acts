## 未验证或有限验证

- 内置测试浏览器的 URL 安全策略拒绝 `file://` 地址。没有绕过该限制，因此**没有在测试浏览器中实测双击打开本地文件**。已验证的是：同一完全内嵌 HTML 经本机 HTTP 提供时能够运行、无需其他文件或外部网络资源。双击是交付设计和推荐启动方式，但该协议路径未标为已测试。
- 没有完成 Edge、Firefox、Safari、手机真机和不同显卡的全覆盖测试，不能保证所有设备相同帧率。
- 未对声卡输出进行人工听音验收；声音生成、介质滤波、静音/音量和节点复用主要通过代码与浏览器音频状态检查。
- 透明水幕、粒子与海面采用实时近似，不是流体求解；没有证明所有自由镜头和每个可能时刻绝无视觉交叠。
- 暂停的任务动画保持静止，但镜头恢复构图可能继续平滑收敛；独立昼夜时钟在启用时继续运行。这是刻意区分的两组控制。

## 复验

执行 `node build.js` 和 `node tests/simulation.test.js`。浏览器打开 `index.html#qa` 或 `深海启航.html#qa`，点击“运行一致性验收”。普通打开不显示开发验收面板。测试需要允许页面运行和浏览器音频上下文；隐藏标签页可能受浏览器节流影响。
