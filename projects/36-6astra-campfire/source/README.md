# 松间 · Camp Still

完整的 Three.js 低多边形露营地，页面标题为 **GPT-6-Astra max 篝火营地**。当前版本为连续大地形：营地位于广阔松林草地之中，周围地面一直延伸到雾中的远山。

## 直接运行

双击 `dist/index.html` 即可打开。单独交付的 `GPT-6-Astra max 篝火营地.html` 与该文件内容相同，可以独立复制到其他目录使用。

HTML 内嵌 Three.js、OrbitControls、样式、全部几何体和程序生成纹理，不依赖 CDN、在线字体、外部图片、模型或后端。运行时无需联网。

需要支持 WebGL 2 的现代浏览器，并启用硬件加速。若浏览器限制本地文件，可使用下方本地服务器方式。

## 开发与构建

安装 Node.js 20 或更新版本。在项目目录打开终端：

```sh
npm ci
npm run build
npm start
```

浏览器访问 `http://127.0.0.1:4173`。本地服务器仅提供静态 HTML，绑定本机回环地址，没有后端业务或数据收集。

- `npm ci`：根据锁文件安装 Three.js 0.180.0 和 esbuild 0.25.10。首次安装依赖需要联网。
- `npm run build`：将代码、样式和依赖打包为 `dist/index.html`。
- `npm start`：预览已构建的文件，无需安装依赖也可运行此 Node.js 静态服务器。
- `npm run dev`：构建一次并启动预览；不包含自动监听。
- 修改源码后，重新执行 `npm run build`，再刷新页面。
- 端口冲突时可设置环境变量 `PORT`。例如 PowerShell：`$env:PORT=4174`，然后 `npm start`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标拖动 / 单指拖动 | 围绕营地旋转 |
| 鼠标滚轮 / 双指手势 | 缩放视角 |
| 日光 / 星夜 | 平滑切换环境、月光、星空与营灯 |
| 营地篝火开关 | 同步切换火焰、火星、烟雾、炭火发光和篝火点光源 |
| 右上角归位 / 点击松间标志 | 恢复当前屏幕尺寸对应的全景 |

点击场景后可使用键盘：方向键旋转、`+` / `-` 缩放、`R` 归位、`N` 切换昼夜、`F` 切换篝火。界面按钮支持 Tab 焦点与 Enter / 空格操作。

## 场景与实现

- 约 840 × 840 场景单位的连续三角形山地，近处网格精细、远处稀疏；没有悬浮底座、外露土层侧壁或可见的孤岛边缘。
- 776 棵近景与远景松树形成林地，草坡、远山与雾衔接。长步道从远处延伸到帐篷与火堆，扩大后的水塘嵌入地面凹地。
- 两顶帐篷、两把折叠椅、石圈篝火、木柴堆、营桌、杯具、炊具、冷藏箱、背包与树桩。
- 浅水塘、涟漪、芦苇、石块、草丛、野花和蘑菇沿营地与周围林地自然分布。
- 夜间星光、萤火、悬挂灯串、独立营灯，以及实际照亮场景网格的篝火点光源。
- 火焰由低边数锥体组成；火星用点粒子；烟雾用透明低面数网格。
- 白天采用柔和阴影；篝火和营灯使用点光源。为了运行效率，只有主方向光生成阴影贴图。
- 林地树木和外围石块使用实例化渲染；步道与草丛使用合并几何体。限制像素比、缓存材质、限制缩放与俯仰角；后台页面暂停场景更新。
- 所有场景资源均由代码生成，固定随机种子保证构图可复现。
