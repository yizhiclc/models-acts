# 原始提示词

【任务】

请使用 Three.js 创建一个可运行的低多边形风格露营地场景。

【场景要求】

1. 场景应具有明确的“户外露营地”特征，可包含帐篷、篝火、树木、石头、地面起伏以及其他合适的自然或露营元素。具体元素的数量、类型、尺度和分布由你根据整体构图自行决定。
2. 各元素应共同组成一个完整、自然的小型露营场景，而不是若干物体彼此孤立地摆放。
3. 场景中应有一个明确的露营核心区域，例如围绕篝火、帐篷或休息区域形成视觉中心；具体布局可以自由设计。
4. 篝火应具有简单的火焰、发光或其他动态表现，并能够对附近环境产生可辨认的照明效果。
5. 默认镜头应能完整展示露营地的主要构图和空间层次。

【交互要求】

1. 支持旋转和缩放视角。
2. 提供白天 / 夜晚切换。
3. 夜晚时环境整体变暗，人工或火焰光源更加明显。
4. 提供控制篝火点燃 / 熄灭的交互。
5. 篝火熄灭后，其火焰效果和对附近环境的照明应同步消失或明显减弱。

【视觉要求】

整体采用统一的低多边形风格。重点是清晰、舒服、有层次，并形成完整的露营氛围。

不要求复杂模型或照片级真实效果。可以根据整体效果自由决定地形形状、植被数量、露营设施、装饰元素、色彩、材质和灯光配置。

额外加入的元素应服务于“低多边形露营地”这一主题，不应明显削弱场景主体或影响运行稳定性。

【技术要求】

- 使用 Three.js。
- React 或原生实现均可，无需后端。
- 页面打开后直接看到完整场景。
- 保持动画和视角操作稳定流畅。

【交付要求】

交付完整可运行项目，并说明运行方式。

如果实际进行了构建、运行或功能测试，请如实说明测试结果；未验证的部分不要声称已经验证。
