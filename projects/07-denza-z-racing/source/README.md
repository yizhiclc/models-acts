# DENZA Z · Racing Studio

根据测试包中的 `PROMPT.md` 和五张参考图，用 Three.js 构建的腾势 Z 2026 Racing 赛道版交互式外观展示。全部车辆几何由代码生成，没有使用现成的完整汽车模型。

## 启动

需要 Node.js **20.19+ 或 22.12+**。在此项目目录打开终端：

```sh
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 **http://127.0.0.1:5173/**。Windows 也可双击项目内的 **启动展厅.cmd**，自动安装缺少的依赖并打开浏览器。

构建和查看正式版本：

```sh
npm run build
npm run preview
```

构建结果位于 `dist/`，可部署到任何静态网站服务器。交付包已包含一次实际构建的 `dist/`。请通过 HTTP 服务访问，不要直接双击 `index.html`：浏览器的 ES 模块需要 HTTP 环境。

依赖安装需要访问 npm；运行时使用本地 Three.js、程序生成的材质纹理和本地参考图片，不调用外部模型、字体、HDR 或 API，不需要后端。

## 模型与材质

- 以米为单位建立统一坐标，前后轴分别位于 X = −1.39 / +1.39，轴距 2.78 m。
- 四个轮心高度均为 0.356 m；轮胎外半径 0.356 m；地面 Y = 0。左右轮心位于 Z = ±0.832 m。
- 车身由纵向截面和横向曲率采样生成。侧面下边界根据轮拱半径 0.398 m 截断，真实留出轮胎空间，不用车身遮住轮胎。
- 独立的前后包围、曲面灯组、硬顶、挡风玻璃、侧窗、车门缝、隐藏式把手、后视镜和充电口。
- 轮组包含程序化轮胎、胎侧文字、胎纹、分叉轮辐、轮毂、制动盘纹理和独立黄色卡钳。
- 碳纤维前铲和侧裙、侧部风道、固定式尾翼、镂空支架、端板、后扩散器及纵向导流鳍。
- 车漆使用金属与清漆层，玻璃有独立颜色和反射；轮胎、轮圈、金属、碳纤维使用不同材质。碳纤维、制动盘及格栅纹理由 Canvas 生成。
- 使用程序化环境反射、主光/补光/轮廓光、静态阴影和接触阴影。无运行时远程素材依赖。
- 合并轮辐几何、复用轮胎和轮圈几何，并按材质合批静态网格；限制像素比和刷新频率，隐藏页面时停止绘制。

这是基于图片和任务尺寸的**近似外观重建**，不是官方 CAD 或精密逆向模型。页面列出的 4870 × 1990 × 1350 mm 是任务提供的参考尺寸；曲面、后视镜、前铲和尾翼附件存在造型近似及外伸量。刹车盘孔为纹理表现，格栅为材质表现，侧窗为深色反射材质；不包含驾驶模拟或可开启车门。

## 项目结构

```text
denza-z-racing/
├─ index.html
├─ package.json
├─ package-lock.json
├─ vite.config.js
├─ 启动展厅.cmd
├─ src/
│  ├─ car.js          # 参数化车身、灯组、座舱、轮组、空气动力学结构
│  ├─ main.js         # 场景、光照、摄像机、交互与页面
│  └─ style.css       # 桌面和移动布局
├─ scripts/
│  └─ check-geometry.mjs # 对称性、有限坐标、轮拱间隙检查
├─ public/
│  ├─ favicon.svg
│  └─ references/     # 用户测试包的原始五张参考图
├─ dist/              # 实际生成的静态构建
└─ VALIDATION.md      # 实际检查结果
```

## 验证

已实际安装依赖、运行 Vite、执行生产构建并通过浏览器检查正式构建页面。详细环境、交互检查和帧率结果见 `VALIDATION.md`。帧率由当前页面实际渲染统计，硬件、像素比和浏览器会影响结果，不作跨设备保证。

可运行 `npm run check:model` 重复检查车身截面的有效性、左右对称性和轮拱对轮胎包络的间隙。
