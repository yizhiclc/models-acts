# 原始提示词

【任务】

请使用 Three.js 创建一个可运行、可交互观察的悉尼歌剧院（Sydney Opera House）3D 场景。

作品应以悉尼歌剧院为绝对视觉中心，在有限尺度内表现建筑与悉尼港湾之间完整而具有辨识度的空间关系。目标是让人打开页面后，无需说明就能辨认出悉尼歌剧院，并从多个角度感受到其独特的雕塑性建筑形态。

【场景要求】

1. 主体必须是具有明确辨识度的悉尼歌剧院，而不是泛化的白色帆形建筑。建筑的整体比例、屋顶壳体、基座、立面以及各主要体量之间的关系应符合其典型形象；具体如何还原，由你根据对悉尼歌剧院建筑形态的理解自行决定。

2. 屋顶壳体是建筑最重要的视觉特征，应具有可信的曲面形态、体积感和空间层次。不同壳体之间需要形成合理的尺度、方向、前后遮挡与组合关系，避免退化成若干相同曲面或简单三角形的机械排列。

3. 建筑需要作为一个完整建筑存在，而不是只有屋顶造型。壳体、下方建筑空间、玻璃立面、基座、台阶与外部平台之间应自然衔接，并在不同观察角度下保持合理的结构关系与尺度感。

4. 场景应体现悉尼歌剧院“临港而立”的特征。水面不应只是背景贴片，而应参与整体构图，并与建筑基座、岸线、天空及适量远景共同形成完整的滨水空间关系。

5. 材质、光照和阴影应能够清楚表现建筑曲面的起伏以及不同区域的质感差异。整体视觉风格可自行选择，但应以真实、清晰地展示建筑形体为前提，避免过度特效掩盖模型本身。

6. 默认镜头应完整呈现建筑及其滨水关系，具有明确的主体构图和空间层次。页面打开后无需调整即可看到作品的主要内容，同时允许从侧面、正面、高位及水面方向进一步观察模型质量。

【交互要求】

- 支持自由旋转、缩放和平移，并提供恢复默认视角的方式。
- 场景在交互过程中应保持稳定流畅。
- 可以自行增加预设观察机位、时间变化、建筑灯光、环境动画、镜头导览、建筑展示模式、信息标注或其他交互。
- 附加功能应服务于建筑观察与整体体验，不应以牺牲建筑质量和构图为代价。

【实现取向】

优先保证：

1. 悉尼歌剧院的建筑辨识度
2. 屋顶壳体的几何质量与空间关系
3. 建筑主体、基座与滨水环境的整体构图
4. 材质、光影与建筑体积感
5. 多角度观察下的模型完整性
6. 交互、动画与运行稳定性

建筑主体应主要通过代码自行构建，不直接加载现成的完整悉尼歌剧院 3D 模型。

除上述目标外，请根据整体效果自行权衡视觉质量、几何复杂度和性能，并主动补充你认为能够增强悉尼歌剧院建筑特征和场所感的正确细节，自行抉择建模方法、曲面生成方式、几何细分程度、材质方案、灯光数量、环境范围、动画实现、UI 风格或项目组织方式。

【技术要求】

- 使用 Three.js 完成核心 3D 场景，React 或原生实现均可，无需后端。
- 创建完整前端项目，可使用 Vite 等常见构建工具，确保安装后能够直接启动和构建。
- 页面加载后直接进入完整场景，不依赖用户先执行额外操作。
- 代码应具有清晰的场景和模型组织，不应出现影响正常体验的运行错误。

【交付要求】

- 交付完整可运行项目，并说明安装、启动和构建方式。
- 如果实际进行了构建、运行或功能验证，请如实说明；未验证的部分不要声称已经通过。
