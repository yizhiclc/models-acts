# 原始提示词

【任务】
请用 Three.js 和 WebGPU 创建一个可运行的"大航海时代帆船与热带海湾"3D 场景:一艘 17～18 世纪风格的木质帆船航行在逼真的实时海面上,附近有热带岛屿与浅滩。本作品的重点是水:海面在物理行为和视觉表现上都应接近真实海洋,并与船体、尾流和海岸形成联动,而不是在一张会动的水面上摆一艘船。

【场景要求】
1. 帆船由代码建模,结构完整、一眼可辨认:木质船壳、甲板与舷墙、至少两根桅杆、横桁与多组船帆、基本索具、船舵、船首斜桅。桅杆立于船体,帆围绕桅杆组织。细节可适度概括,不追求复刻具体舰船。
2. 海面采用风驱动的频谱海浪(FFT 海洋或等价的多方向谱叠加)。要求:
   - 遵守深水色散关系,长波比短波传播更快;
   - 由多级联或等价方法组成不同尺度的波浪,近看有细碎波纹,远看有大尺度涌浪,且无明显的平铺重复痕迹;
   - 有水平位移带来的尖峰波形,而不只是垂直起伏。
3. 破碎与泡沫:白浪出现在波峰堆叠、折叠的位置,有生成和逐渐消散的过程,而不是随机贴在整片海面上。浅水与礁石附近,波浪随水深变陡、破碎,岸边有往复的水线和泡沫。
4. 浮力:在船体上取多个采样点读取当前局部水面,由浮力、重力和阻尼积分得到升沉、俯仰、横摇和航行偏航,不能用 sin() 等预设周期驱动摇摆。船所读取的水面必须与画面上的水面一致。船体应处于合理的吃水状态,水线处水面不得穿进船内。
5. 尾流:在 GPU 上维护一个跟随船的持久水面扰动场,船的位置、速度和朝向持续向其注入扰动,扰动随时间传播、扩散、衰减。船首有排开水面的浪,船尾有可辨认的 V 形尾迹和泡沫航迹。加速时尾流变长变强,转向时尾流弯曲,停船后逐渐消散。
6. 场景包含至少一座带沙滩的热带岛屿和一段浅滩或礁石区,岛屿从海床升起。深水到浅水的颜色、透明度和海底可见度自然过渡。
7. 默认为晴朗热带白天或日落。打开页面即可看到帆船、附近海面和部分岛屿。

【水体视觉】
- 水色由物理关系决定:按水深和波长做吸收,浅水可见海底与焦散,深水偏深蓝绿。
- 菲涅尔反射:掠射角反射天空,俯视时透出水下颜色;天空要有真实感的大气,海面反射它。
- 太阳高光呈随波面闪烁的细碎光斑,而不是一个模糊的圆。
- 波峰薄处有透光;泡沫为半透明、有细节的白沫,而不是纯白贴图。
- 远处海面与天空在地平线自然融合(大气透视);法线细节随距离平滑过渡,镜头移动时无闪烁、无 LOD 接缝。
- 可以使用 HDR 渲染与色调映射,光照要同时表现木船壳、布帆、沙滩和海水的材质差异。

【交互要求】
1. 提供"风速"滑杆,从平静到强风浪连续变化。变化时波浪平滑过渡,无相位跳变;波高、破碎程度、泡沫、船的运动幅度、帆的状态和尾流随之变化。
2. 提供"航速"控制。
3. 提供太阳高度或时间控制,方便观察水色与反射的变化。
4. 支持旋转、缩放、平移和复位;设置几个预设机位。

【实现取向】
优先保证:海面的物理与视觉真实感、船随浪运动的可信感、尾流与船速航向的对应、近岸变化、海湾整体构图。波浪算法、浮力采样方式、岛屿与植被细节等自行取舍;船体和岛屿可适度概括,把主要精力放在水上。

主波浪可以是解析或频谱叠加,但凡是声称"受船或岸影响"的部分，比如尾流、船周扰动、泡沫、近岸水线必须带有跨帧状态。参数应参考真实量级(单位为米,重力 9.81,船长 30～50 米,涌浪波长数十至上百米)。

【技术要求】
- 使用 Three.js WebGPURenderer(TSL 或 Compute 均可),海面频谱、尾流场和泡沫的核心计算实际运行在 GPU 上;WebGPU 不可用时给出提示而不是白屏。
- 所有模型和材质均由代码生成,不加载现成的帆船场景或海洋资源。React 或原生均可,无需后端。
- 在工作区创建完整项目,可用 Vite,确保安装后可直接构建启动,并在 package.json 中锁定 three 版本。
- 页面打开后直接进入完整场景,长时间运行和视角操作保持稳定流畅。
