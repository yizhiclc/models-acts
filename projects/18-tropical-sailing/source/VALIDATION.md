## 已执行

- `npm install --no-audit --no-fund`：依赖安装成功。
- `npm run check`：全部 JavaScript 语法检查通过。
- `npm run build`：Vite 生产构建成功；同一构建生成完整内嵌的 `海湾航记.html`。
- 完整项目 ZIP 已另行解压到干净目录，`npm ci --no-audit --no-fund` 和 `npm run build` 再次成功；压缩包 CRC 检查通过，包含锁文件、源码、构建输出和许可证。
- HTML 结构检查：恰有一个内嵌模块脚本，无外部脚本、样式表或模块预加载依赖；包含修复后的独立前帆着色器。
- 开发版通过本机 `localhost:5187` 启动，GPU 初始化、海浪 / 尾流 Compute、场景编译、渲染和九点 GPU 水面回读均实际运行。
- 单文件通过静态服务器 `localhost:5188/海湾航记.html` 独立加载成功，未依赖开发服务器的模块、CDN、模型或贴图。单文件新标签的控制台 error / warn 为空，`ready=true`、`gpuErrors=[]`、`queryError=null`。
- 内置浏览器安全策略拒绝 `file://` 协议导航，因此未在该浏览器验证双击直接打开；没有绕过策略，采用已验证的 localhost 静态服务器方式。
- 检查了海湾、追船、水线、俯瞰机位；风速与太阳滑杆；停船 / 加速；暂停及镜头跟随。窄屏和桌面布局均实际查看过。
- 静风 + 停船测试：目标风速、目标航速设为 0 后，实际航速降到约 `0.0020 m/s`；GPU 扰动峰值由约 `0.0645 m` 降到 `0.00486 m`，泡沫总量由约 `643` 降到 `203`。近岸仍可能继续生成泡沫，因此全场泡沫总量不必为零。这组记录来自修整前的 24 分量版本，用于验证持久场消散机制，不能作为最终 48 分量版本的海况标定。
- 最终 48 分量海洋曾在 18 m/s、12 kn 条件下连续运行到模拟时间约 `98 s`：`invalidCells=0`，GPU 回读次数 `2033`，`gpuErrors=[]`，`queryError=null`；扰动峰值约 `0.319 m`。这证明当前环境短时数值稳定，不代表长时压力或跨设备认证。
- `18 m/s / 12 kn / 75°` 条件下近景复查船帆修复：前帆不再插入前桅方帆，主帆上沿不再被前桅尾支索穿过，主帆下沿不再出现桅杆和前侧横桁索具造成的缺口。
- 留影预览能生成场景图像。内置浏览器的下载自动化没有返回可用下载路径，因此没有把 PNG 下载功能记为“下载验证通过”；浏览器截图另存为交付预览图。

## 船帆 / 索具修复

1. 方帆安装面由桅杆前方约 0.12–0.22 m 调整到 0.60–0.68 m，超过桅杆最大半径 0.40 m；零鼓帆的帆头和帆脚也有空间间距。
2. 左右支索和梯绳移到各自帆组后侧。前桅尾支索改为落在两根桅杆之间，消除原先跨越主帆的斜线。
3. 前桅上部延伸到 29.4 m，使前支索从上方避开前桅顶帆。
4. 前三角帆改为细分网格和独立的横向鼓帆材质，布置在局部 `z ≥ 16.1 m`；强风下前方方帆最远约 `z = 13.9 m`，仍留出约 2 m 间距。
5. 关键前支索拆成独立直线段，避免曲线插值越过连接点造成额外穿插。

这些修复是模型装配和运动包络间距修复，不是新增了布料与绳索碰撞解算器。

## 未验证 / 限制

- 未做数小时持续运行、GPU 设备丢失实测、低端显卡 / 手机真机矩阵。
- 未做物理实验数据对照；波高、吸收、泡沫和刚体响应仍是实时近似模型，详见 README。
- 没有对每一条索具、每一种相机角度进行自动化碰撞证明；已经复查用户标注的部位及强风最大鼓帆状态。
- 当前环境帧率读数随窗口尺寸、后台状态、编译和截图变化，不作为性能承诺。
- WebGPU 不可用与非安全上下文分支已在源码中实现中文错误提示；没有通过禁用显卡的方式验证所有失败路径。
