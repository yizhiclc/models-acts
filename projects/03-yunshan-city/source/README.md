# 云山巨城

一卷可以走入的体素山水：九片城区跨越群山与溪谷，听瀑天阙依崖而起，石阶从低处水埠延伸至揽月亭。作品使用实时三维几何绘制，可自由查看，也可沿道路游览。

## 启动

需要 Node.js 18 或更新版本，以及支持 WebGL 2 的现代浏览器。

在本文件所在目录打开终端，运行：

```sh
npm start
```

然后访问 **http://localhost:5173/**。

Windows 也可以双击 `Start.cmd` 启动服务，再打开上述网址。

**无需 npm install，无需构建，运行时无需联网。** Three.js、控制器、代码与样式均已包含在项目中。请通过本地服务打开，不要直接双击 HTML 文件。

若端口被其他程序占用：

```sh
npm start -- --port 5174
```

此时访问 http://localhost:5174/。终端内按 Ctrl+C 关闭服务。

## 操作

| 模式 / 功能 | 操作 |
| --- | --- |
| 览山 | 拖动旋转，滚轮缩放，右键拖动平移；触屏使用单指旋转、双指缩放与平移 |
| 入城 | 点击“循山入城”自动沿道路前进；可随时暂停，拖动环顾 |
| 沿路步行 | W / S 前后移动，A / D 转头；选择 1×、4×、12× 速度 |
| 游览进度 | 拖动入城面板的进度条；点击六个行记驿点直接抵达 |
| 自由飞行 | 拖动转向，W A S D 飞行，Q / E 升降，Shift 加速 |
| 日月 | 拖动底部时间轴，或点击子夜、日出、正午、日落；独立按钮暂停 / 继续时间 |
| 时间速度 | 默认现实 20 分钟经历一天，也可选择 5 分钟或 60 分钟 |
| 舆图 | 展示城区、水系与登山路线；点击地图前往最近的游览驿点 |
| 画面 | 云图标开关流云；相框图标保存 PNG；全屏图标进入全屏 |
| 快捷键 | 0 返回全景，1—6 抵达驿点，H 隐藏界面，F 全屏，Esc 返回全景 |
| 空格 | 入城模式暂停 / 继续行走；其他模式暂停 / 继续昼夜 |

右下角 **?** 中提供完整说明与画质设置。自动画质会根据初始运行情况调整分辨率和阴影；也可自行选择“精致光影”或“流畅游览”。

## 场景与实现

- 九片城区：漱玉埠、千灯坊、青麓书院、长风关、望川城、栖霞坊、云阙上城、松风禅院，以及瀑布旁的听瀑天阙。
- 城市横跨约一公里的山地，包含街市、院落、书院、寺院、关楼、塔楼、园林、泊船与亭阁。核心登临路线约 1.36 公里，从水岸上升至海拔 376 米的亭台。
- 建筑采用 0.2 米的构件量化；山体表面使用 6 米合并体素，远山使用 16—20 米的较粗表面。不会逐个创建 0.2 米小立方体来堆砌整座山。
- 山体、远山、建筑、水系和桥阶均为实时三维几何，没有用远景贴图代替城市规模。
- 使用实例化合并建筑、树木与街道构件；地形使用合并表面几何。动画水流、瀑布飞沫、缓慢流云与日月持续更新。
- 连续日夜系统协调太阳与月亮的位置、天空、雾色、环境光、星空及窗灯。夜间以月光保留山体层次。
- 入城模式提供固定道路上的贴地导览，自由飞行允许任意查看。**没有角色、建筑碰撞、寻路或 NPC 模拟**；自由飞行仅设地面高度下限。
- 桌面浏览器适合完整键鼠游览；窄屏与触屏可使用全景手势、路线自动行走和屏幕控制。
