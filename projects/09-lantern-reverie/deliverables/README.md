# 东风夜放花千树 · 上元灯境

基于 Three.js 的可漫游元宵夜街景，灵感来自辛弃疾《青玉案·元夕》。

## 运行

直接用现代浏览器打开 `index.html` 即可。成品已经打包，无需联网或安装依赖。需要浏览器支持 WebGL 2，建议开启硬件加速。

也可在本目录运行 `node server.cjs`，然后访问 `http://127.0.0.1:4173`。

## 操作

- 按住画面拖动：环视。
- W / A / S / D 或方向键：前后左右移动。
- Q / E：下降、上升；Shift：加速。
- 滚轮：沿视线靠近、远离。
- F、双击天空，或点击“放一场烟花”：燃放烟花。
- R 或点击左上角标志：回到初见。
- “循光巡游”：自动游览；拖动或移动可随时恢复自由操作。
- 右侧三个观景点：长街灯市、花树流光、凌空望月。
- 手机和平板：拖动环视，左下方向键移动。
- 右上角：环境音、全屏、操作说明。操作说明中可以暂停场景动画。

默认关闭声音，尊重系统“减少动态效果”设置。粒子动画暂停时仍可自由移动视角。

## 修改源码

`src/scene.js` 包含场景、程序化建筑与纹理、烟花粒子、镜面反射、泛光、漫游控制和合成环境音。
`style.css` 包含响应式中文界面。`scene.bundle.js` 为可离线运行的打包结果。

```sh
npm install
npm run build
npm start
```

Three.js 使用 MIT 许可证。所用场景几何与纹理由代码生成，无远程模型、图片或音频请求。
