# 天阙 · 中国古典宫城

可直接运行的 Three.js 体素中国古典建筑群。页面打开即呈现整座宫城，整体为虚构的中式皇家建筑群。

## 场景规模

- 宫城约 610 × 780 米，占地约 47.6 公顷。
- 71 座殿阁楼台：重檐主殿、配殿、山门、钟鼓楼、两座九层宝塔、角楼、长廊与园林亭阁。
- 主殿宽 132 米，最高屋脊装饰约 75 米；九层宝塔约 125 米高。
- 2,720 株松柏、银杏与阔叶树，7,638 株花草，25 座石桥及一座木桥；护城河、双侧水渠与四处荷花水院。
- 城外连续起伏的山脊与丘陵、蜿蜒河流、护城河支流、沙质河岸、芦苇、野花、草坡和林地；入城大道与环城步道连接六座城外亭阁。
- 朱红立柱、金色琉璃瓦、青瓦、斗拱、屋脊吻兽、飞檐、门钉、窗棂、灯笼、石狮、华表、铜鼎和旌旗。
- 晨曦、日暮、月夜三种光影：低角度阳光、柔和长阴影、屋檐接触阴影、天空环境反射、金瓦和水面高光、灯火泛光与远景雾。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+；本机使用 Node.js 24.16.0。

```sh
npm ci
npm run dev
```

打开终端提示的地址，通常为 http://localhost:5173/ 。Windows 也可双击 `Windows启动.cmd`，首次运行会自动安装依赖。另有独立交付的 `GPT6.1sol max 中国古典建筑.html`，所有代码和样式均已内嵌，可直接在支持 WebGL 2 的浏览器中打开，无需安装依赖或联网。

## 构建与成品预览

```sh
npm run build
npm run preview
```

默认成品预览地址为 http://localhost:4173/ 。`dist/` 是完整静态成品，可部署到静态网站服务。请通过 HTTP 服务打开，浏览器直接双击 `dist/index.html` 可能阻止 JavaScript 模块加载。

## 操作

- 左键拖动旋转，滚轮缩放，右键拖动平移。
- 触屏单指旋转，双指缩放和平移。
- 顶部切换宫城全景、中轴俯瞰、重檐主殿、园林水榭、山河远眺。
- 底部切换晨曦、日暮、月夜；“环绕”开始自动转动，再次点击暂停。
- 右下角按钮恢复当前预设视角；右上角进入全屏。
- 聚焦画面后，左右方向键旋转，`+` / `-` 缩放，`R` 恢复视角。

## 项目结构

```text
index.html             页面元数据与入口
src/main.js            渲染、相机、光影、交互、帧率及自适应清晰度
src/palace.js          程序化建筑、树木花草、水系、装饰与实例化体素
src/landscape.js       连续地形、河床河岸、道路与贴地自然植被
src/style.css          场景界面与移动屏幕布局
scripts/check-scene.mjs 几何范围与场景规模检查
package.json           固定版本的 Three.js 和 Vite，运行命令
package-lock.json      依赖锁定
dist/                  构建成品
Windows启动.cmd        Windows 一键启动
```

## 性能与验证

建筑和植被合并为六组 `InstancedMesh`，约 10.6 万个体素；含地形共约 134 万个三角形。重复构件复用几何和材质，地形和水面由程序生成。桌面阳光阴影为 4096 分辨率，初始小屏使用 2048；静态阴影在光照变化时重新计算。接触阴影以较低分辨率计算，画面持续监测帧率，并按需降低渲染分辨率和接触阴影负载。

`npm run check` 会检查建筑与植被规模、地形及实例几何是否有效、城墙垛口是否异常拉长，以及城外树木是否贴地、是否避开水面和步道。浏览器实际帧率取决于显卡、屏幕大小和浏览器硬件加速，右下角显示当前实测值。

实际验证：几何检查及生产构建通过（71 座建筑、2,720 株树木，其中城外 2,312 株；7,638 株花草；106,195 个体素；64,224 个地形三角形）。已在本机浏览器中检查五个观景视角、晨曦/日暮/月夜、自动环绕、恢复视角与 390 × 844 的屏幕布局。本机预览约 180 FPS，其他设备表现取决于硬件。单文件打包检查确认脚本与样式完整内嵌、没有外部资源依赖，且 JavaScript 语法检查通过。

没有后端，也不需要图片资源或外部字体服务。
