# 松溪小镇 · 桌面微缩铁路

一个使用 **Three.js 0.180.0 + Vite 7.1.7 + 原生 JavaScript** 制作的前端沙盘，没有后端。页面打开后直接显示完整沙盘，火车默认运行。

按追加要求，沙盘长、宽均扩大至最初版本的 **1.5 倍，实际面积为 2.25 倍**。默认机位拉近，沙盘采用铺满页面的展示区，操作栏悬浮在底部。

## 安装与启动

需要 Node.js 20.19+ 或 22.12+。建议使用当前 LTS 版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 `http://127.0.0.1:5173/`。依赖由锁文件固定；也可以使用 `npm install` 安装。

```bash
npm run build     # 生成 dist/ 静态部署文件
npm run preview   # 预览构建结果
npm test          # 运行列车运动与停站测试
```

`dist/` 可以部署到常见静态网站服务。请通过 HTTP 服务访问，不要直接双击 HTML 文件。

## 使用方式

- 点击圆形按钮运行或暂停；暂停会同时冻结车厢位置和车站停留倒计时。
- 速度滑块支持 0.25–2.00 倍速度。速度不会改变约两秒的停站时长。
- 列车每次抵达松溪站都会停留约两秒，随后自动继续运行。
- 点击“白天／夜晚”切换暖色傍晚与夜景。夜景包含发光路灯、车站照明、部分建筑窗户和车厢窗户。
- 鼠标拖动旋转，滚轮缩放；触屏单指旋转、双指缩放。右侧按钮可放大、缩小或恢复机位。
- 点击“复位”恢复确定的初始机位、列车位置、1.00 倍速度、傍晚光照和默认运行状态，清空圈数与停站计时。
- 点击沙盘使其获得键盘焦点后：空格运行／暂停，方向键旋转，`+ / -` 缩放，`R` 复位，`N` 切换昼夜。

## 场景与运动

沙盘包含有厚度和木纹的木制展示底座、草地地形、开槽河道、两座铁路桥、道路跨河桥、车站站台与雨棚、面包房、邮局、旅舍、住宅、钟楼、果园、菜圃、树木、路灯、座椅和微缩人物。采用圆润树冠、斜屋顶、金属栏架及圆柱形车头，没有使用体素模型。

轨道由两段直线和两段半圆构成，位置及切线在四个连接处连续。轨道几何、枕木、车头和车厢共用同一条按弧长参数化的路线。三节车体分别采样各自的路程位置及前后转向架位置，保持固定路程间距与独立朝向；连接器连接相邻车体的真实端点。

停站采用事件式时间推进，分别消耗行驶、停留和继续行驶的时间，较大的时间步也不会跳过车站。暂停直接冻结模拟时间；页面进入后台再返回时不补跑隐藏期间的路程。

静态模型按材质合并，轨枕和碎石使用实例化；轮轴独立动画。阴影采用缓存并隔帧更新，慢设备自动降低渲染分辨率，保留全部场景与交互。木纹、草地和屋顶纹理由 Canvas 生成，不依赖外部模型或图片。Google Fonts 为可选界面字体，网络不可用时自动使用系统字体。

## 已执行验证（2026-09-30）

- `npm test`：**8 项测试通过**，检查闭合接缝、弧长速度、独立车厢间距、两秒停站、暂停冻结、跨越时间步事件、复位和无效输入。
- `npm run build`：**Vite 生产构建成功**；已实际打开生产构建页面，未发现缺失资源或 JavaScript 错误。
- Microsoft Edge / Playwright：在 **1440 × 960** 桌面视口验证了默认运行、暂停、速度滑块、昼夜灯光、缩放、旋转、机位与列车复位、实际到站、暂停停站计时以及自动离站。
- **390 × 844** 移动视口：页面和控制栏没有水平溢出，整个沙盘可见。
- 浏览器检查未发现 JavaScript 或 WebGL 错误。具体记录见 `verification.json`，日景、夜景和移动端截图随项目提供。

浏览器功能检查使用软件 WebGL；没有执行真实硬件 GPU 的帧率基准，因此不把该环境的帧率解释为硬件性能结论。原生 WebMCP 接口在测试浏览器中不可用，其可选工具注册未通过原生环境验证；这不影响网页按钮和沙盘运行。

## 文件结构

```text
index.html                 页面入口与元数据
src/main.js                界面、控件、状态显示及可选浏览器工具
src/scene.js               几何建模、材质、灯光、相机和动画渲染
src/simulation.js          闭合轨道与列车／停站模拟
src/style.css              桌面和移动端界面
tests/simulation.test.js   核心运动行为测试
public/favicon.svg         站点图标
package-lock.json          锁定依赖
dist/                      构建后的静态网页
verification.json          实际浏览器检查结果
preview-*.png              实际页面截图
```
