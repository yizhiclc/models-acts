# 原始提示词

```
你是一位自动控制原理的解题专家。当前目录下有：

- 题目/题目汇总.md  —— 4 道题的题干，每道题末尾用 Markdown 图片语法引用了题图（如 images/图01-1.jpg）
- 题目/images/      —— 全部题图

请先完整读取 题目/题目汇总.md，再逐张打开题图，看清每张信号流图的结构，然后逐题求解。

【总体要求】
1. 只依据题干与题图作答。不要联网搜索，不要参考任何答案册或题库。
2. 题图是位图，弧线可能相互交叉、节点很小。请先确认每个节点的编号、每条支路的方向与增益，必要时说明你的读图结论，不要跳过这一步。
3. 必须使用梅森增益公式求解，逐步展开，不允许直接给出结果。
4. 不要遗漏回路。回路的条数、互不接触回路的组数都要明确列出。
5. 图中节点默认按从左到右编号，输入节点记为 R（或 N），输出节点记为 C（或 Y）。

【每题必须输出以下 6 项】
（1）支路清单：按「起点 → 终点：增益」逐条列出你识别到的全部支路，包含前向支路与反馈支路。
（2）单独回路：L1 = …、L2 = …，每条都要注明经过哪些节点。
（3）互不接触回路：列出所有互不接触的回路组合；若没有，写「无不接触回路」。
（4）特征式：Δ = 1 − ΣLi + ΣLiLj − ΣLiLjLk + …，先写求和形式，再代入并化简。
（5）前向通路与余子式：P1 = …，Δ1 = …（有几条写几条）。
（6）最终传递函数：用梅森增益公式写出，并同时给出因式形式与展开的多项式形式（分母按 s 降幂排列）。

【输出格式】
- Markdown，每题的标题写成 `## 第 N 题`。
- 数学公式用 LaTeX：行内 `$...$`，独立成行 `$$...$$`。
- 第 3 题有两个输入，请分别给出 `C(s)/R(s)` 与 `C(s)/N(s)`。
- 4 题全部作答完毕后，在末尾加一张汇总表：题号 | 单独回路条数 | 互不接触回路组数 | 最终传递函数。

【禁止】
- 不要省略任何一步推导。
- 不要用「显然」「易得」跳过回路搜索。
- 不要输出与解题无关的寒暄或免责声明。
```
