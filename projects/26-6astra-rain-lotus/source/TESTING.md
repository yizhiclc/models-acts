# 实际执行的验证

验证日期：2026-10-02。环境：Windows、Node.js 24.16.0、Microsoft Edge 154.0.4258.48、NVIDIA Lovelace WebGPU 适配器。浏览器自动化采用 Playwright 的无头模式。以下结果不能直接代表其他设备的性能。

## 构建与基础数值检查

- `npm run build`：成功生成 `dist/`。Vite 提示主包大于 500 kB；实际压缩前约 842 kB，gzip 约 237 kB。这是体积警告，不是构建失败。
- `npm run test:physics`：通过水珠合并体积、质心和动量守恒检查，通过粒径单位转换、下落速度关系、离散稳定性界限和共享不规则岸线检查。

## 实际 GPU 计算检查

通过 `npm run test:gpu` 执行原生 WebGPU 计算并读回完整波场。检查时关闭风和连续降雨，暂时移除植物掩码，以分离待测现象；障碍测试单独插入竖直反射墙。

| 项目 | 读回结果 | 结论 |
| --- | --- | --- |
| 单滴传播 | 0.375 秒时高度平方加权半径 0.07191 m；1.5 秒时 0.29336 m | 波包确实离开落点向外传播，约 0.197 m/s |
| 粒径响应 | 同速度 4 mm / 2 mm 雨滴最大波高比 7.99986 | 按体积增强，非相同效果缩放播放 |
| 双滴叠加 | 双滴结果与两次单滴结果之和的相对误差 3.38 × 10⁻⁷ | 多扰动叠加在同一持久场中 |
| 无外力衰减 | 再演化 7.5 秒后，测试能量代理量剩余 1.38% | 暂停输入后场继续演化并衰减 |
| 反射障碍 | 障碍内部波高最大值为 0；源侧与无墙结果的差异平方和 1.17 × 10⁻⁶ | 固体边界阻挡并改变返回波 |
| 有限性 | 早期及传播后所有高度、速度均为有限数 | 未出现 NaN / Infinity |

其中“能量代理量”定义为 `Σ(h² + 0.002 v²)`，用于自动回归比较，不是完整物理能量积分。反射测试证明离散障碍改变波场，没有声称对衍射角谱或真实液体进行实验标定。

## 界面与持续运行

执行并通过：

- 暂停降雨、单滴按钮及自动无风状态。
- 全景、临水、荷叶特写、俯视四个机位。
- 精细画质开启与关闭、窗口放大及 390 × 844 窄屏布局，未发生水平溢出。
- WebGPU 接口缺失时显示明确的错误面板。
- 精细画质、雨量 100%、风速 2.5 m/s，连续运行 **60 秒**，无浏览器脚本错误或 WebGPU validation 错误。

持续测试结束时记录到累计 155,627 次击水、56,571 次叶面碰撞、24,022 次水珠合并和 12,204 次滴落；渲染中的水珠数为 2,233，荷叶 54 片。计数包含持续测试前的检查阶段，不作为严格流量测量。1440 × 960 测试末次短窗口帧率为 131 fps；这不是最低帧率或整段平均帧率。资源计数为 189 个几何体和 29 张纹理，未作显存分析。

机器可读日志：[tests/results/report.json](tests/results/report.json)。

## 生产包和画面检查

最终 `dist/` 用 `vite preview` 启动并实际打开。生产包验证了初次渲染、缩放、平移、复位及精细画质往返切换，未记录脚本或 GPU 错误。静止视角的累积历史权重为 127/128；鼠标旋转后立即降为 0。结果见 [tests/results/production.json](tests/results/production.json)。

## 单文件离线验证

`npm run build:single` 成功生成 855,060 字节的 `rain-lotus.html`。在 Edge 154.0.4258.48 中直接以 `file://` 打开，浏览器上下文设为离线，未加入额外 WebGPU 启动标志。记录到的唯一资源请求是 HTML 文件本身。

实际 WebGPU 初始化、降雨击水、暂停、单滴、荷叶机位、精细画质往返切换和窗口缩放均通过；未记录脚本或 GPU 错误。机器可读结果：[tests/results/singlefile.json](tests/results/singlefile.json)。此验证不代表所有浏览器都允许本地文件使用 WebGPU。
