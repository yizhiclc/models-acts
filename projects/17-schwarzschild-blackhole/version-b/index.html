模型与边界

非旋转、无电荷黑洞的 Schwarzschild 外部时空。每个像素在光线所在平面内用 RK4 积分零测地线，而非扭曲贴图或预设光环。

G = c = M = 1
ds² = −(1−2/r)dt² + dr²/(1−2/r) + r²dΩ²
u = 1/r
d²u/dφ² = −u + 3u²
b_crit = 3√3
g = √(1−3/r) / [√(1−2/r_obs)(1−Ωλ)]

盘内缘位于 ISCO = 6rg，采用零内缘力矩的 Novikov–Thorne 稳态薄盘通量与各向同性局部黑体辐射。旋转气体的引力红移和相对论多普勒效应共同包含在 g 中；可见光按普朗克谱积分，总辐射按 g⁴ 变换。

这是理想化、可交互的外部光学模拟，不是黑洞形成或磁流体模拟。未包含自旋、盘厚度、散射、偏振、回返辐射与吸积反馈；星场为程序生成，曝光与显示色调映射不属于物理量。光线有有限步数和角步长，极窄高阶像可能未被屏幕像素分辨。
