# 实际运行记录

检查日期：2026-09-11。按交付要求仅进行基础验证，不代表所有浏览器、显卡和参数组合均已测试。

## 构建与物理

实际执行：

```text
npm run precompute
npm test
npm run build
```

物理预计算约 11 秒；输出原始测地线数据约 32.1 MiB，压缩后约 16.8 MiB。内嵌为 Base64 后，独立 HTML 约 23 MiB。

8 项物理测试全部通过：

- Schwarzschild 临界冲量参数和光子圆轨道。
- RK4 对零测地线一阶积分的保持。
- ISCO 转向点与弱场偏折极限。
- Novikov-Thorne 零力矩边界、远场通量、温度缩放。
- 引力/横向/有符号纵向多普勒频移。
- 冲量参数查找坐标的可逆性。
- GPU 数据表与独立小步长积分的抽样比较。
- 有限距离观察者的初始角积分。

预计算最大记录守恒残差：`3.1377567211166024e-11`。

测试样本中查表的最大半径倒数相对误差：`1.0613862862945113e-5`。半径本身对应的相对误差同阶；此值不是所有光线的误差上界。

解压后的测地线数据 SHA-256：

```text

```
